## Fields

| Field                  | Label          | Kind                | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------- | -------------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`                |                | `string`            | Yes      | Event name                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `description`          |                | `string`            | No       | Event details                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `starts_at`            | Starts         | `datetime`          | No       | The instant the event starts, ISO 8601. An instant carries no zone of its own however it is written; the timezone field is what anchors the event's wall-clock hour.                                                                                                                                                                                                                                                                                                                                                                            |
| `ends_at`              | Ends           | `datetime`          | No       | The instant the event ends, ISO 8601.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `duration`             |                | `number`            | No       | Duration in seconds; the length of each occurrence of a series that states no ends_at. A write is refused unless it is from 0 to a century.                                                                                                                                                                                                                                                                                                                                                                                                     |
| `place`                |                | `string`            | No       | Location                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `latitude`             |                | `number`            | No       | Venue latitude                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `longitude`            |                | `number`            | No       | Venue longitude                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `url`                  | URL            | `url`               | No       | Event link                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `precision`            |                | `enum`              | No       | How much of the start instant is actually known, for an event dated from memory or from a source that gave only a year. Narrows an instant that exists; it does not say the event has no instant, which is what all_day says. Values: `year`, `month`, `day`, `time`.                                                                                                                                                                                                                                                                           |
| `status`               |                | `enum`              | No       | Whether the event will happen. A tentative event might not, a confirmed one will and a canceled one will not. Moving an event changes its time, not its status. Values: `tentative`, `confirmed`, `canceled`.                                                                                                                                                                                                                                                                                                                                   |
| `notes`                |                | `string`            | No       | Personal annotations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `recurrence`           |                | `array` of `string` | No       | RFC 5545 recurrence property lines (RRULE, RDATE, EXDATE). Present on the series itself; occurrences are computed from it at read time rather than stored, starting with starts_at itself. A write is refused when a line cannot be read or is not applied (EXRULE, an RDATE period), when it carries more than one RRULE, more than 40,000 characters in all or more than 1,000 added and removed dates, when the rule names no date that exists after the start, or when it produces no occurrence within the bound a read unfolds a rule to. |
| `all_day`              |                | `boolean`           | No       | True when the event occupies whole days rather than a span of time. A whole day has no instant, so a reader must take the calendar date from starts_at read in timezone and never re-derive it in the reader's own zone, which is how an all-day event ends up on the wrong day for anyone further west. Absent or false means the event has real start and end instants.                                                                                                                                                                       |
| `timezone`             | Time Zone      | `string`            | No       | IANA time zone the event's schedule keeps its wall-clock hour in, e.g. Europe/Berlin. Stored times stay instants; a recurring series expands in this zone so occurrences keep their local hour across a daylight-saving transition. Absent means the rule advances in UTC. This is the start zone: an event that ends somewhere else states that in end_timezone. A write is refused unless the zone database resolves it as a named zone.                                                                                                      |
| `end_timezone`         | End Time Zone  | `string`            | No       | IANA time zone the event ends in, when that differs from timezone: a flight lands in a zone it did not depart from, and both ends are wall-clock facts a person reads off a ticket. Absent means the event ends in the zone it started in. Recurrence expands in timezone only; this field never anchors a rule. A write is refused unless the zone database resolves it as a named zone.                                                                                                                                                       |
| `attendees`            |                | `array` of `object` | No       | The people invited, one entry each, in the order written. An entry names a person by name, email or both, and holds no item ID: an app finds the person behind an entry by matching its email to the email addresses a person holds. response is the reply, from the participation status of RFC 5545; needs_action means no reply yet.                                                                                                                                                                                                         |
| `attendees[].name`     |                | `string`            | No       | The attendee's name as the source gives it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `attendees[].email`    |                | `email`             | No       | The attendee's email address                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `attendees[].response` |                | `enum`              | No       | The attendee's reply to the invitation. Values: `needs_action`, `accepted`, `declined`, `tentative`.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `original_starts_at`   | Original Start | `datetime`          | No       | For an event that replaces one occurrence of a series, the start instant of the occurrence it replaces. Its series is named by a parent-of edge.                                                                                                                                                                                                                                                                                                                                                                                                |
