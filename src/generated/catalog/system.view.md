## Fields

| Field     | Kind                | Required | Description                                                                                                                                                                                                                                                                                                                                                                           |
| --------- | ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `title`   | `string`            | Yes      | The view's name                                                                                                                                                                                                                                                                                                                                                                       |
| `query`   | `object`            | No       | Which items the view lists. `types`: type identifiers, each with its subtypes; empty or absent lists every type the reading key reads. `tier`: `library`, `feed` or `all`; absent is `all`. `state`: `active`, `archived` or both; absent is both. `filter`: an expression in the listing grammar's `filter`. `beneath`: an item id; the item and everything under it by `parent-of`. |
| `layouts` | `array` of `object` | Yes      | How the view shows its items, in order, at least one. Each layout has an `id` unique in the view, a `kind` (`list`, `table`, `board`, `gallery`, `calendar`, `timeline`, `chart` or `map`), and an optional `title`, `sort`, `group`, `shown` and the options its kind takes. A layout never narrows which items the view lists                                                       |
