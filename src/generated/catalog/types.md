## Core types

| Type                                   | Description                                                                                                                                                                                                                        | Subtypes                                                                                                                                                                                                                                                                                                               |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`core.bookmark`](/catalog/bookmark)   | Content you captured from elsewhere: a saved URL, a highlight, an excerpt, a clipped paragraph.                                                                                                                                    |                                                                                                                                                                                                                                                                                                                        |
| [`core.entity`](/catalog/entity)       | A non-person entity: a company, band, team, charity, brand, school.                                                                                                                                                                | [`person`](/catalog/entity#core-entity-person), [`place`](/catalog/entity#core-entity-place)                                                                                                                                                                                                                           |
| [`core.event`](/catalog/event)         | Something that happens at a time.                                                                                                                                                                                                  |                                                                                                                                                                                                                                                                                                                        |
| [`core.file`](/catalog/file)           | A file or binary reference: the generic fallback for non-media files.                                                                                                                                                              | [`audio`](/catalog/file#core-file-audio), [`image`](/catalog/file#core-file-image), [`video`](/catalog/file#core-file-video)                                                                                                                                                                                           |
| [`core.highlight`](/catalog/highlight) | A user's engagement with content: the highlighted passage plus optional annotation. The canonical relationship (what was highlighted) is carried by a references edge; the moment of highlighting is the item's own `occurred_at`. |                                                                                                                                                                                                                                                                                                                        |
| [`core.media`](/catalog/media)         | Content produced by someone that the user engages with: a film, podcast, book, article, song, show.                                                                                                                                | [`album`](/catalog/media#core-media-album), [`article`](/catalog/media#core-media-article), [`book`](/catalog/media#core-media-book), [`episode`](/catalog/media#core-media-episode), [`film`](/catalog/media#core-media-film), [`series`](/catalog/media#core-media-series), [`song`](/catalog/media#core-media-song) |
| [`core.message`](/catalog/message)     | A light, cross-platform message. Threading is edge-based via in-thread; reply trees via parent-of. Tool-specific richness lives in app namespaces.                                                                                 |                                                                                                                                                                                                                                                                                                                        |
| [`core.note`](/catalog/note)           | Text content you created.                                                                                                                                                                                                          |                                                                                                                                                                                                                                                                                                                        |
| [`core.task`](/catalog/task)           | Something to be done.                                                                                                                                                                                                              |                                                                                                                                                                                                                                                                                                                        |

## System types

| Type                                       | Description                                                                                                                                                                                                                                                                 |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`system.connection`](/catalog/connection) | An OAuth client this user has authorized, written when the user approves the client's consent or device sign-in. `kind` is `app`. Lifecycle bounded to active \| revoked. Has no tier.                                                                                      |
| [`system.folder`](/catalog/folder)         | A folder's settings, held here and shared by every machine bound to the folder; each machine chooses only the directory. The settings are written only through `/folders`: created, changed at a version, and revoked. Lifecycle bounded to active \| revoked. Has no tier. |
