## Core types

| Type                                     | Description                                                                                                                                                                                                                 |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`core.bookmark`](/catalog/bookmark)     | Content you captured from elsewhere: a saved URL, a highlight, an excerpt, a clipped paragraph.                                                                                                                             |
| [`core.collection`](/catalog/collection) | Items of any type that you gather together. Members join it through the in-collection edge, and it can hold any item but another container.                                                                                 |
| [`core.entity`](/catalog/entity)         | Any named entity: a person, a company, a band, a team, a charity, a brand, a school or a place. `core.entity.person` and `core.entity.place` narrow it.                                                                     |
| [`core.event`](/catalog/event)           | Something that happens at a time.                                                                                                                                                                                           |
| [`core.file`](/catalog/file)             | A file or binary reference: the generic fallback for any file that has no more specific type.                                                                                                                               |
| [`core.highlight`](/catalog/highlight)   | A user's engagement with content: the highlighted passage plus optional annotation. What was highlighted is linked with an `excerpt-of` edge, not `references`; the moment of highlighting is the item's own `occurred_at`. |
| [`core.media`](/catalog/media)           | Content produced by someone that the user engages with: a film, podcast, book, article, song, show.                                                                                                                         |
| [`core.message`](/catalog/message)       | A light, cross-platform message. Threading is edge-based via in-thread; reply trees via parent-of. Tool-specific richness lives in app namespaces.                                                                          |
| [`core.note`](/catalog/note)             | Text content you created.                                                                                                                                                                                                   |
| [`core.task`](/catalog/task)             | Something to be done.                                                                                                                                                                                                       |

## System types

| Type                                       | Description                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`system.connection`](/catalog/connection) | An OAuth client this user has authorized, written when the user approves the client's consent or device sign-in. `kind` is `app`. Lifecycle bounded to active \| revoked. Has no tier.                                                                                                                                   |
| [`system.folder`](/catalog/folder)         | A folder's settings, held here and shared by every machine bound to the folder; each machine chooses only the directory. The settings are written only through `/folders`: created, changed at a version, and revoked. Lifecycle bounded to active \| revoked. Has no tier.                                              |
| [`system.view`](/catalog/view)             | A saved list of items, held here and shared by every app: which items, in what order and how they group. How an app shows them is the app's own. Written only through `/views`: created, changed at a version, and deleted, which removes it at once with no trash. Lifecycle bounded to active \| revoked. Has no tier. |
