## Core types

| Type                                     | Description                                                                                                                 |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| [`core.bookmark`](/catalog/bookmark)     | Something you saved from elsewhere, such as a link, a highlighted excerpt or a clipped paragraph.                           |
| [`core.collection`](/catalog/collection) | A named group of items of any type, such as a reading list or the plans for a trip.                                         |
| [`core.entity`](/catalog/entity)         | Someone or something with a name, such as a person, company, band, team, charity, brand, school or place.                   |
| [`core.event`](/catalog/event)           | Something that happens at a time, such as a meeting, a flight or a birthday.                                                |
| [`core.file`](/catalog/file)             | A file you keep, such as a PDF or a spreadsheet.                                                                            |
| [`core.highlight`](/catalog/highlight)   | A passage you highlighted, with any note you added.                                                                         |
| [`core.media`](/catalog/media)           | Something someone made that you read, watch, listen to or play, such as a film, podcast, book, article, song, show or game. |
| [`core.message`](/catalog/message)       | A message you sent or received, such as a text or a chat message.                                                           |
| [`core.note`](/catalog/note)             | Text you wrote, such as a thought, a meeting note or a list.                                                                |
| [`core.task`](/catalog/task)             | Something you need to do, such as booking flights or sending an invoice.                                                    |

## System types

| Type                                       | Description                                                                                                                    |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| [`system.connection`](/catalog/connection) | An app you signed in to Marfa, with the access you gave it and when it last used it.                                           |
| [`system.folder`](/catalog/folder)         | A folder kept in sync with Marfa, with which items it holds and how new files are filed, shared by every machine that uses it. |
| [`system.view`](/catalog/view)             | A saved list of items, with the order and grouping you chose, shared by every app.                                             |
