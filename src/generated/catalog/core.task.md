| ------------------- | --------- | ------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `title`             |           | `string`            | Yes      | What needs doing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `description`       |           | `string`            | No       | Brief context                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `body`              |           | `string`            | No       | Detailed description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `due_at`            | Due       | `datetime`          | No       | Deadline                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `starts_at`         | Starts    | `datetime`          | No       | When to start                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `completed_at`      | Completed | `datetime`          | No       | When completed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `status`            |           | `status`            | No       | Where the task stands. Values: `not_started` in `not_started`, `in_progress` in `in_progress`, `completed` in `completed`, `canceled` in `canceled`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `priority`          |           | `enum`              | No       | Task priority. Values: `low`, `medium`, `high`, `urgent`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `place`             |           | `string`            | No       | Location                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `precision`         |           | `enum`              | No       | Temporal precision. Values: `year`, `month`, `day`, `time`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `url`               | URL       | `url`               | No       | Related link                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `assignees`         |           | `array` of `object` | No       | The people the task is assigned to, one entry each, in the order written. An entry names a person by name, email or both, and holds no item ID: an app finds the person behind an entry by matching its email to the email addresses a person holds. It has the members of an attendee of an event, without a response.                                                                                                                                                                                                                                                                                                                                                                                                  |
| `assignees[].name`  |           | `string`            | No       | The assignee's name as the source gives it, such as a login                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `assignees[].email` |           | `email`             | No       | The assignee's email address                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `notes`             |           | `string`            | No       | Personal annotations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `recurrence`        |           | `array` of `string` | No       | RFC 5545 recurrence property lines (RRULE, RDATE, EXDATE) for a task that repeats. The series starts at due_at, or at starts_at when the task has no due_at, and advances in UTC because a task has no timezone. The server keeps and checks the rule but does not unfold it: GET /occurrences answers events only. A write is refused when a line cannot be read or is not applied (EXRULE, an RDATE period), when it carries more than one RRULE, more than 40,000 characters in all or more than 1,000 added and removed dates, when the rule names no date that exists after the start, when it produces no occurrence within the bound a read unfolds a rule to, or when the task has neither due_at nor starts_at. |
