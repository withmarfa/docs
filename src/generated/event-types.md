| Event                | Sent to              | When it is sent                                                                                                                                            | Statements                                                                                                                                                                |
| -------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `item.created`       | Streams and webhooks | A write creates an item.                                                                                                                                   | `events/create-announced`                                                                                                                                                 |
| `item.updated`       | Streams and webhooks | A write changes an item.                                                                                                                                   | `events/update-announced`, `events/update-edges-only-announced`, `housekeeping/enrichment-announced`, `types/move-announced`, `items/folder-announced`, `views/announced` |
| `item.trashed`       | Streams and webhooks | An item moves to the bin, or a cascade revokes a `system.*` item.                                                                                          | `items/delete-announced`, `items/trash-cascade-announced`, `events/owner-trash-announced`, `housekeeping/feed-expiry-announced`, `events/cascade-revoke-announced`        |
| `item.restored`      | Streams and webhooks | An item in the bin is restored.                                                                                                                            | `items/restore-announced`, `events/owner-trash-announced`                                                                                                                 |
| `item.purged`        | Streams and webhooks | An item is destroyed.                                                                                                                                      | `items/purge-announced`, `events/owner-trash-announced`, `events/sweep-purge-announced`, `views/delete-announced`                                                         |
| `item.state_changed` | Streams and webhooks | A transition moves the item it names to another state, into and out of the bin included, or a key revokes a folder. A delete and a restore do not send it. | `items/transition-announced`, `events/job-announced`, `items/folder-announced`, `events/delete-no-state-change`, `events/restore-no-state-change`                         |
| `metadata.changed`   | Streams and webhooks | A tag operation commits for an item, whether or not it changes the tags, or an extension namespace is written or deleted.                                  | `items/tag-announced`, `items/extension-announced`                                                                                                                        |
| `rows.changed`       | Streams and webhooks | A batch changes the rows of one table of an item, on a copy stream too.                                                                                    | `tables/rows-event`, `tables/rows-event-copy-sent`                                                                                                                        |
| `edge.created`       | Streams and webhooks | An edge is created.                                                                                                                                        | `edges/create-announced`, `events/edge-bulk-announced`, `events/edge-inline-announced`, `versions/copy-edges-announced`                                                   |
| `edge.updated`       | Streams and webhooks | An edge is written: its properties, or one of its ends moving to another item.                                                                             | `edges/update-announced`, `edges/move-announced`, `events/edge-bulk-announced`                                                                                            |
| `edge.deleted`       | Streams and webhooks | An edge is deleted.                                                                                                                                        | `edges/delete-announced`, `events/edge-inline-announced`, `items/purge-edges`, `events/sweep-purge-edges`                                                                 |
| `attention.raised`   | Streams and webhooks | A check of what needs the owner's attention first finds an entry, or the server first meets a fault.                                                       | `events/attention-raised`, `events/attention-fault-at-once`                                                                                                               |
| `stream_cursor`      | Streams              | First, when the stream read the log as it opened: where the log stood then.                                                                                | None                                                                                                                                                                      |
| `stream_live`        | Streams              | Once the catch-up is over: everything up to its cursor has been sent or withheld, and what follows is live.                                                | None                                                                                                                                                                      |
| `stream_incomplete`  | Streams              | Last, when the stream can no longer deliver what it opened with.                                                                                           | None                                                                                                                                                                      |
| `catchup_too_old`    | Streams              | Last, when the log no longer holds the events after the `Last-Event-ID` the client sent.                                                                   | None                                                                                                                                                                      |
| `cursor_ahead`       | Streams              | Last, when the `Last-Event-ID` the client sent is past the latest event in the log.                                                                        | None                                                                                                                                                                      |
| `reach_changed`      | Streams              | Last on a copy stream, when its reach changes.                                                                                                             | None                                                                                                                                                                      |
