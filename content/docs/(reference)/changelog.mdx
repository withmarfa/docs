The latest release is first. Each release says what is new for a person, any breaking change and what to do about it, and what changed in the server, the CLI, the core and the SDKs. The notes are the ones on the release's GitHub page, and releases before v0.0.51 are on [GitHub Releases](https://github.com/withmarfa/marfa/releases).

Before you upgrade, read [Upgrade](/run/upgrade). A new release updates the database in place, after it copies the database to a file beside it that ends in `.before-upgrade`.
