The latest release is first. Each release lists what is new for a person, any breaking changes and what to do about them, and the changes to the server, the CLI, the core and the SDKs. The notes are the ones on the release's GitHub page. Releases before v0.0.51 are on [GitHub Releases](https://github.com/withmarfa/marfa/releases).

Before you upgrade, read [Upgrade](/run/upgrade): a new build updates the database in place, after it copies the database to a file beside it.
