An excerpt is an **Excerpt from** one item, and that item lists its **Excerpts**. An excerpt comes from exactly one item, so a second `excerpt-of` edge from it is refused with `400 edge_constraint_violation`. An item can have any number of excerpts.

## When to use it

Use `excerpt-of` for an item that carries text taken from another: a [highlight](/catalog/highlight) from a book, a quote from an article, a clip from a video. A highlight with no title is named after the item it's an excerpt from, such as "Excerpt from The Dispossessed".

Not for a link or a mention in an item's text, which is a [`references`](/catalog/edges/references) edge, or for a note that discusses an item, which is [`about`](/catalog/edges/about) it.

## In the bin

An excerpt holds its own text, so it stays where it is when the item it came from goes to the bin or is purged. A purge removes the edge.

## In a folder

The excerpt's file writes the edge as an `excerpt-of` line.

## Example

A highlight taken from a book:

```json
{
  "edge_type": "excerpt-of",
  "from_id": "01a1f139-b223-7383-8088-a3253b3e9009",
  "to_id": "01a1f139-b217-74ef-b7ca-f406c1e2d8a3"
}
```
