An item lists what it's **Derived from**, and the item it was made from lists what it's the **Basis for**. An item can be derived from any number of items.

## When to use it

Use `derived-from` to record where a made thing came from: a summary of a meeting note, a transcript of a recording, a cleaned-up copy of an imported file, a chart made from a table.

Use another type when the relationship is narrower:

- An item that replaces an earlier one as the current version [`supersedes`](/catalog/edges/supersedes) it.
- A passage taken word for word is an [`excerpt-of`](/catalog/edges/excerpt-of).

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

The from item's file writes the edge as a `derived-from` line.

## Example

A transcript derived from a recording:

```json
{
  "edge_type": "derived-from",
  "from_id": "01a1f139-e0eb-71f0-a815-035d71915e61",
  "to_id": "01a1f139-e0e3-76e4-afde-38925980a6d6"
}
```
