A message is **In thread** in exactly one thread, and the thread lists its **Messages**. `position` orders them.

## When to use it

Use `in-thread` to gather [messages](/catalog/message) that people read on their own, such as the emails of one exchange, under the item that stands for the thread.

A conversation whose messages are never read on their own, such as a chat with an assistant, is one [`core.conversation`](/catalog/conversation) item that holds them as the rows of its `messages` table, with no `in-thread` edges. Not for a comment on an item, which is a [`comments-on`](/catalog/edges/comments-on) edge.

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

The message's file writes the edge as an `in-thread` line.

## Example

The first message in a thread:

```json
{
  "edge_type": "in-thread",
  "from_id": "01a1f139-e0c7-703d-9a80-e4edfc0a1b2c",
  "to_id": "01a1f139-e0bf-7d21-8e3a-5f6b7c8d9e0f",
  "properties": { "position": 0 }
}
```
