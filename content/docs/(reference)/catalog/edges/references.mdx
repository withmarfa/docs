<include cwd>src/generated/catalog/edges.md#references</include>

An item lists what it **References**, and the item it mentions lists what it's **Referenced by**. An item can reference any number of items. [Edges](/build/edges#edge-types) says when to use it and when another edge type fits.

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

A link or an embed in the body writes the edge. A `references` edge that the body doesn't link is written as a `references` line, and the body is left as it is.

## Example

A note that mentions another:

```json
{
  "edge_type": "references",
  "from_id": "01a1f139-e0a7-7b2e-9c4d-1f2a3b4c5d6e",
  "to_id": "01a1f139-e088-76db-afa2-16f1291328f6"
}
```
