An item lists what it **References**, and the item it mentions lists what it's **Referenced by**. An item can reference any number of items.

## When to use it

Use `references` for a link or an embed in an item's text, or for a system's own link from one item to another. A link such as `[[Reading list]]` in a note's body makes one, and so does an embed such as `![[map.png]]`.

Use another type when the relationship says more than a mention:

- An item that discusses another is [`about`](/catalog/edges/about) it.
- A passage taken from an item is an [`excerpt-of`](/catalog/edges/excerpt-of).
- A file that's part of an item is [`attached-to`](/catalog/edges/attached-to) it.

An item can't reference itself: that edge is refused with `400 edge_cycle`, as it is for every edge type.

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

A link or an embed in the body writes the edge. A `references` edge that the body doesn't link is written as a `references` line, and the body is left as it is.

## Example

A note that mentions another:

```json
{
  "edge_type": "references",
  "from_id": "01a1f139-e0a7-7b2e-9c4d-1f2a3b4c5d6e",
  "to_id": "01a1f139-e088-76db-afa2-16f1291328f6"
}
```
