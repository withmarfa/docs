An item lists what it's **About**, and the item it points at lists what it's the **Subject of**. An item can be about any number of items.

## When to use it

Use `about` when an item exists to discuss or report on another one: a review about a film, a meeting note about a project, a notification about a pull request.

Use another type when the relationship is narrower:

- A passage taken from the item, with its own text, is an [`excerpt-of`](/catalog/edges/excerpt-of).
- A link or a mention in the item's text is a [`references`](/catalog/edges/references) edge.
- A comment that belongs to the item is a [`comments-on`](/catalog/edges/comments-on) edge.

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

The from item's file writes the edge as an `about` line:

```yaml
about:
  - "[[The Dispossessed]]"
```

## Example

A note about a book, sent to `POST /edges`:

```json
{
  "edge_type": "about",
  "from_id": "01a1f139-a22f-72a3-972f-3e25c4b4cb09",
  "to_id": "01a1f139-b217-74ef-b7ca-f406c1e2d8a3"
}
```
