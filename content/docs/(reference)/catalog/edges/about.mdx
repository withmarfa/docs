An item lists what it's **About**, and the item it points at lists what it's the **Subject of**. An item can be about any number of items. [Edges](/build/edges#edge-types) says when to use it and when another edge type fits.

## In the bin

Either end can go to the bin, or be purged, and the other stays where it is.

## In a folder

The from item's file writes the edge as an `about` line:

```yaml
about:
  - "[[The Dispossessed]]"
```

## Example

A note about a book, sent to `POST /edges`:

```json
{
  "edge_type": "about",
  "from_id": "01a1f139-a22f-72a3-972f-3e25c4b4cb09",
  "to_id": "01a1f139-b217-74ef-b7ca-f406c1e2d8a3"
}
```
