An edge is a typed, directed link from one item, its **from item**, to another, its **to item**, as [Edges](/build/edges) explains. Every shipped edge type takes any type as its from item, and the table gives the types each may point at. A registered edge type can limit both ends, and a write outside them is refused with `400 edge_constraint_violation`.

<include cwd>src/generated/catalog/edge-types.md</include>

- **Label and reverse label:** the headings an app shows for the two ends. `parent-of` lists a task's `Children` and, read from a child, its `Parent`.
- **Reverse name:** the edge's name read from its to item, used as a frontmatter key in a [synced folder](/folder-rules).
- **Cardinality:** how many edges of the type each end may hold. `many-to-one` lets each from item hold one, `one-to-many` each to item one, and `one-to-one` both.
- **On delete:** what moving an end to the bin does to the other end. `orphan` leaves it where it is. `cascade` moves the to item to the bin with the from item. `with-hosts` makes the from item a **part**: it goes to the bin when its last to item does, and comes back with any of them. A registered type can also be `block`, which refuses the delete.

## Each edge type

- [`about`](/catalog/edges/about): an item is about another.
- [`attached-to`](/catalog/edges/attached-to): an item belongs to another, such as a file to a note.
- [`comments-on`](/catalog/edges/comments-on): a comment, or a reply to one.
- [`derived-from`](/catalog/edges/derived-from): an item was made from another.
- [`excerpt-of`](/catalog/edges/excerpt-of): a highlight, quote or clip taken from an item.
- [`in-collection`](/catalog/edges/in-collection): an item is a member of a container.
- [`in-folder`](/catalog/edges/in-folder): where an item's file sits in a synced folder.
- [`in-thread`](/catalog/edges/in-thread): a message in a thread.
- [`parent-of`](/catalog/edges/parent-of): a hierarchy of parents and children.
- [`references`](/catalog/edges/references): an item's text mentions another.
- [`supersedes`](/catalog/edges/supersedes): an item replaces another.
