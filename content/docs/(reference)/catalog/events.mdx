The table lists every event Marfa sends, where it goes and which writes send it. A write that changes a type, an edge type, a source, a key, the instance's configuration or a webhook subscription sends nothing, and neither does a blob upload ([`events/settings-silent`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/events.md#eventssettings-silent)).

<include cwd>src/generated/event-types.md</include>

- `item.updated` and `edge.updated` come with every write to the item or edge, however little it changes.
- Tags written with an item through `POST /items` or `POST /items/bulk` come in its `item.created` or `item.updated`, with no `metadata.changed`.
- `item.state_changed` comes only for the item a transition names. An item the transition takes to the bin or brings back with it gets `item.trashed` or `item.restored`.
- `attention.raised` goes only to a credential that holds `instance.read`, and never to a stream that names a type or to a copy stream.
- The frames whose names start with `stream_`, and `catchup_too_old`, `cursor_ahead` and `reach_changed`, come only on a stream and describe the stream itself.
