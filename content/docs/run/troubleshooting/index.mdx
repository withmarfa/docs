Each entry is titled by **what you see**: a line in the server's log, a status and code in an API answer, or a line the CLI prints. It gives the cause, then the fix. Search for the message, or open the page for what you were doing.

| Page | What it covers |
| --- | --- |
| [Fix a server that won't start or be claimed](/run/troubleshooting/start-and-claim) | A server that won't start, and claiming an instance |
| [Fix a refused key or sign-in](/run/troubleshooting/credentials-and-access) | Keys, sign-in, and requests refused for access or rate |
| [Fix a folder that won't open or sync](/run/troubleshooting/folders) | A folder that won't open or sync, and a watch that stopped |
| [Fix a Google connector](/run/troubleshooting/google-connectors) | A Google connector's setup and grant |
| [Fix a command that can't find its server or key](/run/troubleshooting/cli) | A command that can't find its server, key or profile |

Some problems belong to one task, so that task's guide covers them, and these pages link to it. An app's or a script's refused write is in [Fix a refused write](/build/fix-a-refused-write), and a working copy that falls behind is in [Fix a working copy that can't catch up](/build/fix-a-working-copy).

If your problem isn't here, the [errors reference](/api-reference/errors) lists every code Marfa answers, and the [CLI](/cli#exit-codes) page lists every exit code.
