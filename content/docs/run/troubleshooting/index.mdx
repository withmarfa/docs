Each entry is titled by **what you see**: a line in the server's log, a status and code in an API answer, or a line the CLI prints. It gives the cause, then the fix. Search for the message, or open the page for what you were doing.

| Page | What it covers |
| --- | --- |
| [Starting and claiming](/run/troubleshooting/start-and-claim) | A server that won't start, and claiming an instance |
| [Credentials and access](/run/troubleshooting/credentials-and-access) | Keys, sign-in, and requests refused for access or rate |
| [Writing](/run/troubleshooting/writing) | Creates and updates that Marfa refuses |
| [Staying in step](/run/troubleshooting/staying-in-step) | Event streams and working copies that fall behind |
| [Folders](/run/troubleshooting/folders) | A folder that won't open or sync |
| [Google connectors](/run/troubleshooting/google-connectors) | A Google connector's setup and grant |
| [The CLI](/run/troubleshooting/cli) | A command that can't find its server, key or profile |

Some problems belong to one task, so that task's guide covers them, and these pages link to it.

If your problem isn't here, the [errors reference](/api-reference/errors) lists every code Marfa answers, and the [CLI](/cli#exit-codes) page lists every exit code.
