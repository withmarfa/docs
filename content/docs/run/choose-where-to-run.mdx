An instance is one server with one database and one folder of files, and it needs little while it waits. **Run it where it can stay on, with a disk that holds your files.**

| Where | Choose it when | Steps |
| --- | --- | --- |
| Your own Mac or Linux computer | It stays on, and you reach it from your own devices | [Install on a Mac or Linux](/run/install) |
| Railway | You want an `https` address and no computer to look after | [Run on Railway](/run/run-on-a-server#on-railway) |
| A server or container platform | You already run one, or use your own supervisor | [Run in a container](/run/run-on-a-server#in-a-container) |

## What a host needs

- **A 64-bit computer Marfa runs on:** a Mac with Apple silicon, or Linux on x86_64 or arm64. There's no build for an Intel Mac or Windows.
- **One server for the database.** Keep a host at one replica, and turn off anything that stops an idle service: the server runs its [health jobs](/run/check-health#see-what-the-jobs-did) and backups in the background.
- **Disk for the database and every file.** Each file's bytes are kept once, beside the database.
- **Memory for the largest file it reads.** The server reads the text of each file you save, and one file may use up to 1 GiB while it does. On a host with less to spare, lower `enrichment_max_memory_bytes`: a file that needs more is skipped and keeps no text.

## Leave room on the disk

The server keeps 128 MiB free on the volume of its data, set by `disk_reserve_bytes`. **A save, a restore or an export that would take the volume below it is refused** with `507 insufficient_storage`, and the instance goes on answering reads. [`marfa attention`](/run/check-health#check-that-all-is-well) names the disk as degraded once less than the reserve, or 64 MiB if that is more, is free.

Leave more room than the reserve for what the server writes beside your data:

- **An [archive export](/run/export-and-restore)** writes temporary files on the same volume while it runs, and the reserve counts them.
- **A [backup folder](/run/back-up-and-restore)** on the same volume holds its own copy of every file, so put it on another disk.
- **An [upgrade](/run/upgrade)** keeps a copy of the database beside it, as `marfa.db.before-upgrade`.

[Check an instance's health](/run/check-health) shows what an instance uses now. [Instance settings](/reference/instance-settings) lists every setting named here.
