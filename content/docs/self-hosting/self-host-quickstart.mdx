The smallest working Marfa server runs against SQLite on disk with filesystem blobs. No external dependencies. Zero-config defaults bring it up in a few minutes.

<Steps>

<Step>

### Clone and install

```bash
git clone https://github.com/withmarfa/marfa
cd marfa
pnpm install
pnpm build
```

</Step>

<Step>

### Start the server

```bash
export API_KEY_SALT="$(openssl rand -hex 32)"
export PORT=8600
node packages/server/dist/index.js
```

`API_KEY_SALT` is the only required environment variable; the rest use sensible defaults — SQLite at `./data/marfa.db`, blobs in `./data/blobs/`, rate-limited at 1000 requests per minute per credential.

</Step>

<Step>

### Bootstrap an admin key

On a fresh server with no existing keys, the first `POST /keys` succeeds without auth — the bootstrap window. Mint your admin credential:

```bash
curl -X POST http://localhost:8600/keys \
  -H 'Content-Type: application/json' \
  -d '{"label":"admin","role":"admin","source":"bootstrap"}'
```

The response carries the plaintext `key` once — store it.

</Step>

<Step>

### Make your first call

```bash
export MARFA_API_URL=http://localhost:8600
export MARFA_API_KEY=marfa_k1_...

curl -X POST $MARFA_API_URL/items \
  -H "Authorization: Bearer $MARFA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"type":"core.note","properties":{"body":"Hello"}}'
```

</Step>

</Steps>

## Production-shape self-host

For multi-tenant, multi-app, or higher-traffic deployments, use Postgres and S3-compatible blob storage:

```bash
export API_KEY_SALT="<long random string, stable across restarts>"
export PORT=8600
export AUTH_MODE=keys
export DB_DIALECT=pg
export DATABASE_URL="postgres://marfa:<password>@<host>:5432/marfa"
export BLOB_BACKEND=s3
export S3_BUCKET=my-marfa-blobs
export S3_REGION=eu-west-2
export CORS_ORIGINS=https://app.example.com
export ENABLE_HSTS=true
node packages/server/dist/index.js
```

Behind a reverse proxy (Caddy, nginx, Traefik) terminating TLS.
