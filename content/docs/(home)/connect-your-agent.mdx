An agent reaches your instance at its MCP address, **your instance's address followed by `/mcp`**, such as `https://marfa.example.com/mcp`, and signs in through your browser. You need an instance: the [Quickstart](/quickstart) starts one.

## Add Marfa to Claude, ChatGPT or another agent

<Tabs items={["Claude Code", "Codex", "Claude", "ChatGPT", "Cursor", "Other agents"]}>
<Tab value="Claude Code">

Install the Marfa plugin for agents, `withmarfa/marfa-plugin`, then ask the agent to connect:

```bash
claude plugin marketplace add withmarfa/marfa-plugin
claude plugin install marfa@withmarfa
```

In a new session, ask it to connect to Marfa and give it your address. To add the server yourself, run `claude mcp add --transport http --scope user marfa <address>/mcp`, then type `/mcp`, choose **marfa** and sign in.

</Tab>
<Tab value="Codex">

Install the Marfa plugin for agents, `withmarfa/marfa-plugin`, then ask the agent to connect:

```bash
codex plugin marketplace add withmarfa/marfa-plugin
codex plugin add marfa@withmarfa
```

In a new session, ask it to connect to Marfa and give it your address. To add the server yourself, run `codex mcp add marfa --url <address>/mcp`, then `codex mcp login marfa`.

</Tab>
<Tab value="Claude">

Claude connects from Anthropic's servers, so **your instance needs a public `https` address** on the standard port, which [Give your instance an address](/run/address) sets up. On claude.ai or in Claude Desktop, open **Customize** > **Connectors**, select **+ Add** > **Add custom connector** (Claude's own term), name it `Marfa`, enter your address followed by `/mcp`, and select **Continue**, then **Add**. Select **Connect** to sign in.

On a Team or Enterprise plan, an owner of the organization adds it in **Organization settings** > **Connectors**, and each member selects **Connect**. [Anthropic's help](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp) lists the plans.

</Tab>
<Tab value="ChatGPT">

ChatGPT also connects from OpenAI's servers, so the instance needs a public `https` address. Where your plan and workspace allow it, open **Plugins** at chatgpt.com, select the plus button, then **Add custom MCP server**. Name it `Marfa`, enter your address followed by `/mcp` under **Connection**, choose OAuth, accept the warning and select **Create as a plugin**. Install that plugin, then connect. [OpenAI's guide](https://developers.openai.com/plugins/deploy/connect-chatgpt) has the details.

</Tab>
<Tab value="Cursor">

Add Marfa to `.cursor/mcp.json` in a project, or to `~/.cursor/mcp.json` for every project:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "marfa": { "url": "https://marfa.example.com/mcp" }
  }
}
```

Open **Customize** in Cursor's sidebar, enable **marfa** and sign in.

</Tab>
<Tab value="Other agents">

Any agent that supports a remote MCP server over Streamable HTTP and signs in with OAuth takes the same address. Follow its own instructions for adding a server by address.

</Tab>
</Tabs>

**The Marfa plugin is for your agent:** it adds Marfa to Claude Code or Codex and brings skills, which its [README](https://github.com/withmarfa/marfa-plugin#readme) describes. It isn't something you install into Marfa.

## Approve what it may reach

Your browser opens your instance's approval page, headed **Allow** and the agent's name. Sign in with your username and password or a passkey, then choose **Full access**, or **Choose access** to give less, such as reading your files and nothing else, and select **Approve**.

- **What to allow** lists everything the agent asked for. A **Can't be undone** line names any power that can't be reversed.
- **Marfa can't confirm who made an agent,** because any program can name itself anything. Approve only agents you trust, and never a link or code someone sent you.
- **Approving with everything new turned off is declining.**
- **Changes that give a write or a permission** need a sign-in from the last fifteen minutes.

An instance with no owner yet is claimed on this page: it first asks for the setup code that Marfa shows where it runs. [See and revoke access](/use/see-and-revoke-access) ends the sign-in later.

## Other ways in

- **A script or an agent that runs on its own** uses a key instead of a browser: [Work from an agent](/use/from-an-agent#an-agent-that-runs-on-its-own).
- **An agent that runs commands** can use [the CLI](/reference/cli).
- **An agent that edits files** can work in a [synced folder](/use/sync-a-folder).
- **Other MCP addresses** shape types and run the instance. [Marfa MCP server](/reference/marfa-mcp-server) lists them.
- **An agent that builds on Marfa** also benefits from the [docs MCP server](/reference/docs-mcp-server), which reaches no one's data.
