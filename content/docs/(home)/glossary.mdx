Marfa uses each word below in one sense, in its code, its API and these docs.

## Items

| Word | What it means |
| --- | --- |
| [**item**](/build/items-and-types) | One record, such as a file, a note or a contact, with a type, a state and properties. |
| [**type**](/build/items-and-types#what-a-type-does) | What an item is, such as `core.note`, and the properties its items hold. |
| [**namespace**](/build/items-and-types#what-a-type-does) | A type identifier's first segment, which says whose the type is, such as `core` for the types Marfa ships or `user` for your own. |
| [**property**](/build/properties-and-metadata#properties) | A named value in an item, governed by its type. |
| [**tag**](/build/properties-and-metadata#tags) | A free-form, flat label on an item, such as `favorite`. |
| [**extension**](/build/properties-and-metadata#extensions) | A JSON object kept on an item under a namespace, by something other than what wrote the item. |
| [**state**](/build/items-and-types#an-items-life) | Where an item is in its life: `active`, `archived`, `trashed` or, for a `system` item, `revoked`. |
| [**bin**](/build/items-and-types#delete-and-purge) | Where a deleted item waits until it's purged. The API calls the state `trashed`. |
| [**purge**](/build/items-and-types#delete-and-purge) | To delete an item in the bin for good, with its edges and parts. Only an item in the bin can be purged, and nothing undoes it. |
| [**tier**](/build/items-and-types#library-and-feed) | The **library**, what a person chose to keep, or the **feed**, what arrived in volume from elsewhere. |
| [**version**](/build/versions) | A number on an item or an edge that rises with each change to its content, not its tags or extensions. A write names the version it read. |
| [**conflicted copy**](/use/conflicts) | A new item, tagged `conflicted-copy`, written when two writes collide, under automatic conflict resolution, on a property whose type keeps both copies. It holds the losing value. |
| [**table**](/build/tables) | Rows in named, typed columns that an item holds, such as the lines of a budget. A row is never an item. |
| [**conversation**](/catalog/conversation) | A `core.conversation` item, whose messages are the rows of its `messages` table. |
| [**collection**](/catalog/edges/in-collection) | A container, such as a [`core.collection`](/catalog/collection) or an album, and the items joined to it by `in-collection` edges. |
| [**view**](/build/views) | A saved list of items, held as a `system.view` that every app shares: a query, a sort and a grouping. Each app chooses how to show it. Not a folder or a collection. |

## Edges

| Word | What it means |
| --- | --- |
| [**edge**](/build/edges) | A directed link from one item, its **from item** (`from_id`), to another, its **to item** (`to_id`). |
| [**edge type**](/catalog/edges) | What an edge is, such as `about`, and the rules its edges follow. |
| [**label**](/catalog/edges) | The heading a type, a field or an edge type shows. An edge type's label heads the from end, such as `Children` on `parent-of`. |
| [**reverse label**](/catalog/edges) | The heading an edge type shows for the to end, such as `Parent` on `parent-of`. |
| [**reverse name**](/catalog/edges) | An edge type's name read from the to item, such as `child-of`, used as a frontmatter key. |
| [**written from**](/catalog/edges) | The end of an edge type whose file writes its edges in a directory, `from` or `to`, or `none` where no file does. |
| [**part**](/catalog/edges) | An item that belongs to another, its **host**, through a `with-hosts` edge, such as a comment. It goes to the bin with its last host. |
| [**attachment**](/catalog/edges/attached-to) | A part by an `attached-to` edge, most often a file, such as a photo on a note. |
| [**excerpt**](/catalog/edges/excerpt-of) | A highlight, quote or clip taken from one item by an `excerpt-of` edge. |
| [**embed**](/reference/folder-rules) | A file an item's body shows, written `![](path)` or `![[file]]`: a `references` edge to the file. |

## Files

| Word | What it means |
| --- | --- |
| [**file**](/build/files) | An item whose type inherits from `core.file` and refers to the blob that holds its bytes. In a directory, each file on disk is one item. |
| [**blob**](/build/files#a-blob-and-the-item-that-names-it) | Bytes stored once by their content hash. An item refers to a blob and never contains one. |

## Changes

| Word | What it means |
| --- | --- |
| [**event**](/build/events) | One entry in the instance's log of what changed. Not a `core.event` item. |
| [**event type**](/catalog/events) | What an event says changed, such as `item.updated`. |
| [**cursor**](/build/events#the-event-log) | The ID of the last event a reader handled, from which it resumes. |
| [**webhook**](/build/receive-webhooks) | A subscription that sends the instance's events to an address. One a service sends in is an **inbound webhook**. |

## Access

| Word | What it means |
| --- | --- |
| [**owner**](/run/sign-in-as-the-owner) | The one person an instance belongs to. |
| [**credential**](/build/access) | A key or an access token. Its permissions and maps say what it reaches. |
| [**key**](/use/manage-keys) | A credential for a script, an agent or a connector, beginning `marfa_k1_`. |
| [**owner's key**](/use/manage-keys#a-key-for-a-connector) | A key with no app behind it, so no change to an app's access ends it. A connector needs one. |
| [**app's key**](/use/see-and-revoke-access#give-less-access-instead) | A key an app made, or one such a key made. It can only be narrowed, and it ends when the owner narrows the app below it or disconnects the app with its keys. |
| [**app**](/build/connect-an-app) | A program the owner signs in to the instance with OAuth, acting within the grant the owner approved. |
| [**grant**](/build/access#how-a-credential-gets-its-access) | What the owner's consent gives one app: the scopes it may use. Not a permission, which a key holds. |
| [**sign-in**](/use/see-and-revoke-access) | One way your instance is reached: a browser you signed in to, an app you approved or a live key. |
| [**access token**](/build/connect-an-app) | An app's credential, beginning `marfa_at_`. |
| [**scope**](/catalog/permissions#oauth-scopes) | One thing an app asks for, such as `core.note:read` or `offline_access`. |
| [**map**](/catalog/permissions#the-five-maps) | One of a key's five lists of the data it reaches: types, extensions, edge types, metadata (registering types and edge types) and the owner's profile. |
| [**reach**](/catalog/permissions) | What a key's permissions and maps let it read and write. For a working copy, the server's proof that what the copy holds was all read under one credential's limits. |
| [**permission**](/catalog/permissions) | The right to a group of operations, such as `audit.read`. It opens no item. |
| [**source**](/build/items-and-types#where-an-item-came-from) | The code an item carries to say what wrote it: a key's own source, one it claims, or an app's, beginning `oauth:`. |
| [**`source_id`**](/build/items-and-types#where-an-item-came-from) | An item's own ID at its source. With `source`, it's the item's natural key. |
| [**local command**](/run/run-on-a-server#the-private-socket) | A request made through the server's private socket, for what no key may do, such as claiming the instance. |
| [**setup code**](/run/troubleshooting/start-and-claim#i-lost-the-setup-code) | A one-time code that lets one person claim a new instance. |

## The instance

| Word | What it means |
| --- | --- |
| [**instance**](/build/architecture) | One Marfa, holding one owner's data. The **server** is the software that answers its requests. |
| [**MCP**](/reference/marfa-mcp-server) | The protocol AI agents use to call tools. An instance serves its tools at `/mcp`, and more at `/mcp/schema` and `/mcp/admin`. |
| [**housekeeping**](/run/check-health) | The jobs the server runs on itself on a schedule, such as purging the bin. |
| [**operation**](/reference/api) | One thing the API does, named by its method and path, such as `GET /items/{id}`, and by its `operationId`. |
| [**contract**](https://github.com/withmarfa/marfa/tree/main/conformance/spec) | The written rules Marfa follows, each checked by tests. |

## Devices and folders

| Word | What it means |
| --- | --- |
| [**device**](/build/working-copies) | A program that keeps a working copy of a slice and a queue of writes through the core, such as an app built on the Swift SDK or the CLI. A directory that follows a folder is a device too. |
| [**working copy**](/build/working-copies#the-working-copy) | A device's own copy of its slice. The server holds the truth. |
| [**slice**](/build/working-copies#the-working-copy) | The part of an instance a working copy holds: a list of types, a tier, and any edge types it keeps every edge of. |
| [**hydration**](/build/working-copies) | A device's full read of its slice from the server, when its copy is new or has expired. |
| [**queue**](/build/working-copies#a-write-made-offline) | A device's writes waiting to be sent. |
| [**drain**](/build/working-copies#a-write-made-offline) | One pass that sends the queue and records each answer as a verdict. |
| [**verdict**](/build/working-copies#verdicts) | What became of a queued write, such as `accepted` or `dead`. |
| [**folder**](/use/sync-a-folder) | A `system.folder` on your instance: a query that decides which items it holds, and the settings every directory that follows it shares. It's named by its ID or its title. Not a directory. |
| [**directory**](/use/sync-a-folder) | A place on a computer's disk that follows a folder, added with `marfa folders add`. Each file in it is an item, and the `marfa folders` commands act on it. Not a folder. |
| [**frontmatter**](/reference/folder-rules) | The `key: value` lines between `---` fences that open a Markdown file in a directory. |

## Connectors

| Word | What it means |
| --- | --- |
| [**connector**](/build/connectors) | A program outside the server, registered under a key of its own, such as one that syncs another service. |
| [**hold**](/build/connector-holds-and-retries) | The lock that lets one process of a connector write at a time. |
| [**agreement**](/build/connectors) | A connector's record of what it and its service last agreed about one item. |
| [**inbound endpoint**](/build/connector-webhooks) | An address on the instance where a service posts inbound webhooks for one source. |

## The CLI

| Word | What it means |
| --- | --- |
| [**CLI**](/reference/cli) | The `marfa` program, the reference client of an instance. |
| [**command**](/reference/cli) | One thing the CLI does, such as `marfa items list`. |

The full vocabulary, with the words Marfa avoids, is [marfa's GLOSSARY.md](https://github.com/withmarfa/marfa/blob/main/GLOSSARY.md).
