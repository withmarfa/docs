A **Marfa plugin** is what you install into an instance. It can be a connector, a family of shared types, or both. WithMarfa publishes these from the [withmarfa/plugins](https://github.com/withmarfa/plugins) repository. A connector's page says what it brings in, what goes back, and the settings you decide. [Install a plugin](/use/install-a-plugin) adds one by name from the [latest release](https://github.com/withmarfa/plugins/releases/latest), which holds only some of these plugins. Any plugin installs from its source folder.
