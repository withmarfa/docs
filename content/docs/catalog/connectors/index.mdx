A **Marfa plugin** is what you install into an instance. It can be a connector, a family of shared types, or both. WithMarfa publishes these from the [withmarfa/plugins](https://github.com/withmarfa/plugins) repository. The latest release is [v0.0.13](https://github.com/withmarfa/plugins/releases/tag/v0.0.13), which lists Tickets. A connector's page says what it brings in, what goes back, and the settings you decide. [Install a plugin](/use/install-a-plugin) adds one from that release, or from a plugin's source folder.
