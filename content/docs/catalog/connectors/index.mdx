A **Marfa plugin** is what you install into an instance. It can be a connector, a family of shared types, or both. WithMarfa publishes these from the [withmarfa/plugins](https://github.com/withmarfa/plugins) repository. A connector's page says what it brings in, what goes back, and the settings you decide.

The [latest release](https://github.com/withmarfa/plugins/releases/latest) installs each of these by name, with the code of every connector it carries. [Install a plugin](/use/install-a-plugin) adds one, [Run a plugin's connector](/use/run-a-plugin-connector) assigns its connector to a machine, and [Install a connector host](/use/install-a-connector-host) is the program that runs it there.
