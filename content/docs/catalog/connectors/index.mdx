A **Marfa plugin** is what you install into an instance. It can be a connector, a family of shared types, or both. WithMarfa publishes these from the [withmarfa/plugins](https://github.com/withmarfa/plugins) repository. A connector's page says what it brings in, what goes back, and the settings you decide.

The [latest release](https://github.com/withmarfa/plugins/releases/latest) installs **Tickets** by name. Clone the repository for any other plugin's source folder. Installing the connectors by name, and the steps to install a connector host, are coming. A connector you install is recorded and does not run until a host is published. [Install a plugin](/use/install-a-plugin) adds one. [Run a plugin's connector](/use/run-a-plugin-connector) is the server half.
