Readwise Reader is not a second connector. `readwise_reader` turns it on. The default is off.

## What it brings

It reads one account's export: each source, such as a book or an article, as `readwise.source`, and each highlight as `readwise.highlight`, joined by `excerpt-of`. A highlight's body is the whole passage. Its title is the first paragraph, as plain text, cut at a word to at most 80 characters.

`readwise_account` is a label you choose, 1 to 64 letters, digits, dots, underscores or hyphens, starting with a letter or a digit. It is not a secret, and it stays the same when you change the token. The token is the secret `readwise_access_token`.

With Reader on, a Reader document is the same source item as its export entry, and a Reader highlight is the same highlight. `readwise_reader_include_feed` set to `true` includes the feed. The default is the saved library only. `readwise.file` holds content Reader keeps for a document, attached to it.

## What goes back

With Reader off, nothing is written to Readwise. A row Reader managed before is still refreshed with a read, and a change you made in Marfa is kept until Reader can be written again.

With Reader on, Reader owns its documents and highlights, not a row that only the export holds, such as a Kindle book. A change to an export-only row is put back. Supported document edits are title, author, summary, notes, tags, reading location, category, language, publication date and image. Highlights take an annotation and tags. The passage itself is read only.

`readwise_reader_inbound_only` set to `true` sends no edits. Archiving a document in Marfa moves it to Reader's archive, and restoring it moves it to Later, unless edits are off. Trash never changes Reader. `readwise_reader_propagate_purge` set to `true` lets a purge in Marfa delete the Reader record. The default is off. More than 20 deletions waiting at once stops the run before Reader is read.

To make a document or a highlight in Reader, set `reader_create` to `true` on the row, with a stable HTTP address for a source, or a parent and passage text for a highlight. A row without that flag is not created there.

## Pictures

`readwise_reader_pictures` is `addresses` or `save`. The default, `addresses`, fetches nothing from other websites and lists those pictures as deliberately unkept. `save` fetches each HTTPS picture and stores it as a `readwise.file` attached to the document. The HTML keeps the original addresses. Pictures on Readwise's own storage are saved either way. Any other value stops the connector at the start.

## Install

Store the token and the account label as [Give a connector its settings and secrets](/use/connector-settings) describes. The plugin's `plugin.json` lists every setting, including the API addresses and the largest document saved (256 MiB unless you set `readwise_content_max_bytes`).

Install the plugin from its source folder, as [Install a plugin](/use/install-a-plugin) describes. Its connector runs on a connector host ([Run a plugin's connector](/use/run-a-plugin-connector)).
