An edge is a typed, directed link from one item, its source, to another, its target, as [Properties, metadata and edges](/properties-metadata-and-edges#edges) explains. Any type can be the source of every edge type.

<include cwd>src/generated/catalog/edge-types.md</include>

Each edge type has two headings. The label names the source's end of an edge and the reverse label the target's end: `parent-of` lists a note's `Children` and, read from the child, its `Parent`. Registering an edge type needs a label and takes a reverse label as an option. An edge type with no reverse label names both ends alike, such as `Related to`, and an app shows one list for both directions. Both headings are for people. The reverse name is different: it is the edge's name read from its target, used as a frontmatter key. In a [synced folder](/guides/sync-a-folder), the source item's file writes the edge, unless its section below gives `written_at`: `target` puts it in the target item's file under its reverse name, and `none` in no file.
