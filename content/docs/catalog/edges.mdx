An edge is a typed, directed link from one item, its source, to another, its target, as [Edges](/edges) explains. Every shipped edge type takes any type as its source, and the table gives the types each may point at. A registered edge type can limit both ends, and a write outside them is refused with `400 edge_constraint_violation`.

<include cwd>src/generated/catalog/edge-types.md</include>

Each edge type has two headings, both for people. The **label** names the source's end of an edge and the **reverse label** the target's end: `parent-of` lists a note's `Children` and, read from the child, its `Parent`. An edge type with no reverse label names both ends alike, such as `Related to`, and an app shows one list for both directions.

Both labels are optional when you register an edge type. Without a label, Marfa makes one from the last segment of the ID, such as `List Member` for `acme.list-member`. When you change a registered edge type, a label or reverse label you leave out stays as it is. To make a type two-way, send a reverse label equal to the label.

The **reverse name** is different: it is the edge's name read from its target, used as a frontmatter key. In a [synced folder](/run/sync-a-folder), the source item's file writes the edge, unless its section below gives `written_at`: `target` puts it in the target item's file under its reverse name, and `none` in no file.
