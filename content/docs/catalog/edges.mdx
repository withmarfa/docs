`reverse_name` is the name an edge goes by read from its target. In a folder, the source item's file writes an edge. Where an edge's section gives `written_at` as `target`, the target item's file writes it instead, under its reverse name. Where it gives `none`, no file writes the edge: `in-folder` places an item in a folder, and a folder never renders it. An edge type that gives no `written_at` is written at its source.
