An edge is a typed, directed link from one item, its source, to another, its target, as [Properties, metadata and edges](/properties-metadata-and-edges#edges) explains. Any type can be the source of every edge type.

<include cwd>src/generated/catalog/edge-types.md</include>

The reverse name is the edge's name read from its target. In a [synced folder](/guides/sync-a-folder), the source item's file writes the edge, unless its section below gives `written_at`: `target` puts it in the target item's file under its reverse name, and `none` in no file.
