<include cwd>src/generated/catalog/edges.md#references</include>

A link in a directory file's body that resolves to an item, or an embed that resolves to a local file, writes the edge. A `references` edge the body doesn't link is written as a `references` line at the from item's file. A held `references` line can stop the body's edge too ([`folder-documents/body-reference`](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/folder-documents.md#folder-documentsbody-reference)).

## Example

A note, `from_id`, that mentions another, `to_id`:

```json
{
  "edge_type": "references",
  "from_id": "01a1f139-4c04-7b64-b2e4-16fef7e32735",
  "to_id": "01a1f139-49b7-7b82-97be-cd571b51afa9"
}
```
