## Example

The first message, `from_id`, in a thread, `to_id`:

```json
{
  "edge_type": "in-thread",
  "from_id": "01a1f139-edec-7511-a945-ed447f2c55f5",
  "to_id": "01a1f139-6145-77cd-89aa-d449781b0b48",
  "properties": { "position": 0 }
}
```
