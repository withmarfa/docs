A comment is a **Comment on** one item, and that item lists its **Comments**. A comment is on at most one item, which can be another comment: a reply is a `comments-on` edge to the comment it answers. [Edges](/build/edges#edge-types) says when to use it and when another edge type fits.

## In the bin

A comment is a **part** of the item it's on, its **host**:

- It goes to the bin with its host, and so do the replies to it, at every depth. They come back when the host comes back, unless you binned them on their own.
- They're purged with the host.
- Removing the edge leaves both items where they are, and archiving a host changes nothing.

A chain of `comments-on` and `attached-to` edges can't loop back to where it started: the edge that would close it is refused with `400 edge_cycle`.

## Example

A reply to a comment:

```json
{
  "edge_type": "comments-on",
  "from_id": "01a1f139-e03c-735c-9ddf-83a546ebebb5",
  "to_id": "01a1f139-e038-76f6-a27c-0508bfc3ed4d"
}
```
