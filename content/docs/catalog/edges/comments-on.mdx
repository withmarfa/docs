A comment is a **part** of the item it's on, its **host**. [Edges](/build/edges#parts) explains parts, and [`edges/parts-trash`](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/edges.md#edgesparts-trash) says what the bin does with one, replies included. Removing the edge leaves both items where they are.

A chain of `comments-on` and `attached-to` edges can't loop back to where it started: the edge that would close it is refused `400 edge_cycle` ([`edges/parts-cycle`](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/edges.md#edgesparts-cycle)).

## Example

A reply, `from_id`, to the comment it answers, `to_id`:

```json
{
  "edge_type": "comments-on",
  "from_id": "01a1f139-e03c-735c-9ddf-83a546ebebb5",
  "to_id": "01a1f139-e038-76f6-a27c-0508bfc3ed4d"
}
```
