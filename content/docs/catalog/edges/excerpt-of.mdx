<include cwd>src/generated/catalog/edges.md#excerpt-of</include>

An excerpt comes from at most one item, and a second `excerpt-of` edge from it is refused `400 edge_constraint_violation`. It holds its own text, so it stays when the item it came from goes to the bin, and a purge removes the edge.

## Example

A highlight taken from a book:

```json
{
  "edge_type": "excerpt-of",
  "from_id": "01a1f139-b223-7383-8088-a3253b3e9009",
  "to_id": "01a1f139-b217-74ef-b7ca-f406c1e2d8a3"
}
```
