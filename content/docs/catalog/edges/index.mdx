An edge is a typed, directed link from one item, its **from item**, to another, its **to item**, as [Edges](/build/edges) explains. Every shipped edge type takes any type as its from item, and the table gives the types each may point at. A registered edge type can limit both ends, and a write outside them is refused `400 edge_constraint_violation`. A **flat** edge type refuses a from item whose type its to types admit, so a container is never a member ([`edges/collection-no-nesting`](https://github.com/withmarfa/marfa/blob/v0.0.89/conformance/spec/edges.md#edgescollection-no-nesting)). An **acyclic** edge type refuses an edge that would close a loop through other edges of its type ([`edges/cycle`](https://github.com/withmarfa/marfa/blob/v0.0.89/conformance/spec/edges.md#edgescycle)). An edge from an item to itself is refused `400 edge_cycle`, whatever its type.

The [Glossary](/glossary#edges) defines a label, a reverse label, a reverse name and written from. A directory file writes an edge as a frontmatter line named for the edge type, or for its reverse name where `written_from` is `to`, and writes none where it is `none`. [Edges](/build/edges#moving-an-item-to-the-bin) says what each `cascade_on_delete` does.
