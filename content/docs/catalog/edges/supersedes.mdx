- **One each way.** An item supersedes at most one item and is superseded by at most one, so versions form a single line. A second edge at either end is refused `400 edge_constraint_violation`.
- **No loops.** An edge that would lead back to where the line started is refused `400 edge_cycle`.

## Example

A revised lease, `from_id`, that replaces its draft, `to_id`:

```json
{
  "edge_type": "supersedes",
  "from_id": "01a1f139-72f9-7980-97bc-562e51b20652",
  "to_id": "01a1f139-d617-76e5-889b-c765530943bd"
}
```
