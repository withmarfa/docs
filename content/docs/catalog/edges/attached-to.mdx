An attachment is a **part** of the items it's attached to, its **hosts**. [Edges](/build/edges#parts) explains parts, and the contract says what the bin does with one ([`edges/parts-trash`](https://github.com/withmarfa/marfa/blob/v0.0.89/conformance/spec/edges.md#edgesparts-trash), [`edges/parts-restore-own`](https://github.com/withmarfa/marfa/blob/v0.0.89/conformance/spec/edges.md#edgesparts-restore-own) and [`edges/parts-purge`](https://github.com/withmarfa/marfa/blob/v0.0.89/conformance/spec/edges.md#edgesparts-purge)). Removing the edge leaves both items where they are. `part eq true` in a [filter](/build/list-filter-search) finds parts. [Attach a file to a note](/use/work-with-folder-files#attach-a-file-to-a-note) covers attachments in a folder.

## Example

A receipt photo, `from_id`, attached to a task, `to_id`, first among its attachments:

```json
{
  "edge_type": "attached-to",
  "from_id": "01a1f139-e006-7509-a3f6-a953e29cdf67",
  "to_id": "01a1f139-77b1-765d-9c70-cf307fe02e10",
  "properties": { "position": 1 }
}
```
