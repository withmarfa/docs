An attachment is a **part** of the items it's attached to, its **hosts**. It goes to the bin when its last host does, comes back when any host comes back unless you binned it on its own, and is purged with its last host. Removing the edge leaves both items where they are. `part eq true` in a [filter](/build/list-filter-search) finds parts. [Attach a file to a note](/use/work-with-folder-files#attach-a-file-to-a-note) covers attachments in a folder.

## Example

A receipt attached to a task, first among its attachments:

```json
{
  "edge_type": "attached-to",
  "from_id": "01a1f139-e006-7509-a3f6-a953e29cdf67",
  "to_id": "01a1f139-dff2-7c08-9f4e-5b6a7d8e9f10",
  "properties": { "position": 1 }
}
```
