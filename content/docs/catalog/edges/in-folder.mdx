A folder writes these edges itself, with the `path` of the file from the folder's root and a `form` that keeps the order and style of a note's details, never their values, so [every directory writes the note alike](/reference/folder-rules#file-names). No file writes the edge.

Writing one yourself takes write on the item's type, write on `in-folder` and read on `system.folder`. The `path` is required and `form` is optional. A `path` that fails the path rules, a `form` that isn't an object or any other property is refused `400 invalid_properties` ([`edges/folder-path`](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/edges.md#edgesfolder-path)). While a folder is revoked, it keeps its edges and a new edge to it is refused `400 edge_constraint_violation`.

## Example

A note, `from_id`, placed at a path in a folder, `to_id`:

```json
{
  "edge_type": "in-folder",
  "from_id": "01a1f139-a22f-72a3-972f-3e25c4b4cb09",
  "to_id": "01a1f12c-a093-73b4-bf23-b6ab11cbc26f",
  "properties": { "path": "Trips/Lisbon.md" }
}
```
