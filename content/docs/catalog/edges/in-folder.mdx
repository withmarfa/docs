A folder writes these edges itself, with the `path` of the file from the folder's root and a `form` that keeps the order and style of a note's details, never their values, so [every directory writes the note alike](/reference/folder-rules#file-names). No file writes the edge.

Writing one yourself takes write on the item's type, write on `in-folder` and read on `system.folder`. The `path` is required, relative, at most 1,024 characters, with no backslash and no `..`, and `form` is an object. Anything else is refused `400 invalid_properties`. While a folder is revoked, it keeps its edges and a new edge to it is refused `400 edge_constraint_violation`.

## Example

A note placed at a path in a folder:

```json
{
  "edge_type": "in-folder",
  "from_id": "01a1f139-a22f-72a3-972f-3e25c4b4cb09",
  "to_id": "01a1f12c-5d0e-7f3a-8b61-2c9d4e7f1a05",
  "properties": { "path": "Trips/Lisbon.md" }
}
```
