---
title: in-collection
description: Makes an item a member of a container, such as a collection, an album or a series.
job: A builder looks up the ends, cardinality and an example of the in-collection edge type.
---

<include cwd>src/generated/catalog/edges.md#in-collection</include>

- **The to item plays the `container` role.** [`core.collection`](/catalog/collection), `core.media.album` and `core.media.series` do, and so does a registered type that declares or inherits the role. An edge to any other type is refused `400 edge_constraint_violation`.
- **A container is never a member.** An edge from an item whose type plays `container`, declared or inherited, is refused `400 edge_constraint_violation`, with `details.constraint` `nesting` ([`edges/collection-no-nesting`](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/edges.md#edgescollection-no-nesting)).
- **In the bin,** binning a collection leaves its members.

## Example

A note, `from_id`, placed second in a collection, `to_id`:

```json
{
  "edge_type": "in-collection",
  "from_id": "01a1f139-4c04-7b64-b2e4-16fef7e32735",
  "to_id": "01a1f139-e0a3-704f-8070-83f64acc3f15",
  "properties": { "position": 2 }
}
```
