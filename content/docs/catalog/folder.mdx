Marfa writes a folder's settings through the folder operations that [Sync a folder](/guides/sync-a-folder) uses. No item operation writes one: it refuses a `system.*` type with `403 type_not_permitted` ([`items/system-types`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemssystem-types)).
