[Define a type](/guides/define-a-type) shows how to register one. Each rule links to the contract rule behind it.

## Identifier

| Rule | Marfa allows or refuses |
| --- | --- |
| [Grammar](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) | Two or more dot-separated segments, each starting with a lowercase letter and holding lowercase letters, digits, hyphens and underscores. At most 128 characters. |
| [Malformed](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-malformed) | An identifier the grammar refuses is refused `400` `validation_error`. |
| [`app` root](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) | `app.<app name>.<type>`, with exactly two segments after `app`. |
| [`user` root](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) | `user.<type>`, for types you keep for yourself. |
| [Publisher root](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-root-not-prefix) | `<publisher>.<type>`, such as `acme.deal`. The publisher name is the whole first segment, so `core-pub` is allowed. |
| [`core`, `system`, `marfa`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-reserved-namespace) | Refused `403` `forbidden`, whatever the credential. |
| [Other reserved root](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-reserved-scope-root) | Any other root in the list below, except `app` and `user`, is refused `400` `validation_error`. |

## Fields

| Rule | Marfa allows or refuses |
| --- | --- |
| [Keys](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesunknown-key) | A field definition takes `type`, `description`, `required`, `enum_values`, `items_type`, `format`, `searchable`, `maxLength` and `maxItems`. Any other key, such as `minimum`, is refused `400` `invalid_schema`. |
| [Kind](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | `type` is one of the [field kinds](/catalog/field-kinds). An unknown `type` or `format` is refused `400` `invalid_schema`. |
| [`enum`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | Needs `enum_values`, a list of at least one string. |
| [`array`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | Needs `items_type`. |
| [`maxLength`, `maxItems`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | A whole number of at least 1. `maxLength` applies to `string` and `enum`, `maxItems` to `array`. |
| [Array elements](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesarray-items-refused) | Each element must be a value of the field's `items_type`. A write that leaves a wrong element is refused `400` `invalid_properties`, and `details.errors` names the field and position, as `names.1`. |
| [Unnamed `items_type`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesarray-items-unnamed) | An `items_type` that isn't a field kind leaves the elements unchecked. |
| [Name](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-shadows-item) | A name in the reserved field names below is refused `400` `property_shadows_field`. |
| [Thumbnail count](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-one) | At most one `thumbnail` field, counting inherited ones. A second is refused `400` `invalid_schema`. |
| [Thumbnail name](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-name) | Not `title`, `body`, `description` or `name`. An array's `items_type` can't be `thumbnail`. Refused `400` `invalid_schema`. |
| [`title_field`, `body_field`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | Must name a field the type declares or inherits. Refused `400` `invalid_schema`. |
| [Thumbnail as hint](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-hint) | Neither `title_field` nor `body_field` can name a `thumbnail` field. Refused `400` `invalid_schema`. |

## Parent and inheritance

| Rule | Marfa allows or refuses |
| --- | --- |
| [`parent`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-unknown) | Names a registered type. Anything else is refused `400` `validation_error`. |
| [Depth](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-chain) | No loop, and at most ten ancestors. |
| [Subtype may](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeschild-adds) | Add fields, redeclare an inherited field unchanged or with a new `description`, and make an inherited field required. |
| [Subtype may not](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeschild-shape) | Change an inherited field's `type`, `format`, `items_type`, `searchable`, `maxLength`, `maxItems` or `enum_values`, or make a required field optional. Refused `400` `inheritance_violation`. |
| [Write access](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-reach) | A new `parent` that Marfa doesn't ship needs write on that type; keeping one doesn't. Refused `403` `type_not_permitted`. |

### Compatible with

`compatible_with` names a type that yours is readable as, without inheriting from it.

| Rule | Marfa allows or refuses |
| --- | --- |
| [Required fields](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) | Yours requires every field the target requires. |
| [Field kinds](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) | Each target field that yours declares or inherits has the same kind. A `string` target field also accepts `url`, `email`, `datetime`, `date`, `thumbnail` or `enum`, and a `number` accepts `integer`. |
| [Arrays and enums](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) | An `array` has the same `items_type`. An `enum` takes values from the target's. |
| [Format](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) | Where both name a `format`, it is the same one. |
| [Refusal](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-refused) | A claim that doesn't hold, or names an unregistered type, is refused `422` `compatible_with_violation`. |
| [Later changes](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-preserved) | A replacement or deletion that breaks another type's claim is refused the same way, and `details.dependent_type_ids` names the claimants. |
| [Write access](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-reach) | A new target that Marfa doesn't ship needs write on it; keeping one doesn't. Refused `403` `type_not_permitted`. |

## Roles

| Rule | Marfa allows or refuses |
| --- | --- |
| [`roles`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) | Takes `container` alone. Any other role is refused `400` `invalid_schema`. |
| [`container`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/edges.md#edgescollection-target) | The type can be the target of an [`in-collection`](/catalog/edges#in-collection) edge. |

## Merge policy

| Rule | Marfa allows or refuses |
| --- | --- |
| [Shape](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesmerge-policy) | `fields` maps a field the type declares or inherits to a strategy. `default` covers the rest, and is `last_writer_wins` when left out. |
| [Refusal](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesmerge-policy-refused) | A field the type doesn't declare, or another strategy, is refused `400` `invalid_schema`. |

| Strategy | When a later write resolves a collision on the field |
| --- | --- |
| [`last_writer_wins`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md#versionsauto-last-writer) | The item takes the later writer's value. |
| [`keep_both_copies`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md#versionscopy-written) | The item keeps its value, and the later writer's value goes to a new item tagged `conflicted-copy`. |

## Retention policy

| Rule | Marfa allows or refuses |
| --- | --- |
| [Key](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesunknown-key) | Only `feed_days`. |
| [`feed_days` of 1 to 36500](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-values) | A whole number of days. The `feed-expiry` [housekeeping job](/guides/housekeeping) moves the type's feed items to the bin once more than that many days have passed since they arrived. |
| [Counting](https://github.com/withmarfa/marfa/blob/main/conformance/spec/housekeeping.md#housekeepingfeed-expiry-arrival) | From the item's `created_at`. A natural-key upsert keeps it, so a refresh doesn't restart the count. |
| [`feed_days` of `null`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-merge) | The type keeps its feed items, even when a parent sets a window. |
| [`feed_days` left out](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-merge) | The type takes its parent's window. Where no type in the chain sets one, it keeps its feed items. |
| [Other value](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-values) | Refused `400` `invalid_schema`. |
| [Reading](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeslist-declared-policy) | `GET /types/{id}` shows the window after inheritance. `GET /types` shows only the window the type declares. |

The rules behind this page are in the [types](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md), [versions](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md), [edges](https://github.com/withmarfa/marfa/blob/main/conformance/spec/edges.md) and [housekeeping](https://github.com/withmarfa/marfa/blob/main/conformance/spec/housekeeping.md) chapters of the contract.
