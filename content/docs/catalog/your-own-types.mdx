## Identifier

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Grammar | Two or more dot-separated segments, each starting with a lowercase letter and holding lowercase letters, digits, hyphens and underscores. At most 128 characters. | [`types/id-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) |
| Malformed | An identifier the grammar refuses is refused `400 validation_error`. | [`types/id-malformed`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-malformed) |
| `app` root | `app.<app name>.<type>`, with exactly two segments after `app`. | [`types/id-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) |
| `user` root | `user.<type>`, for types you keep for yourself. | [`types/id-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-grammar) |
| Publisher root | `<publisher>.<type>`, such as `acme.deal`. The publisher name is the whole first segment, so `core-pub` is allowed. | [`types/id-root-not-prefix`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-root-not-prefix) |
| `core`, `system`, `marfa` | Refused `403 forbidden`, whatever the credential. | [`types/id-reserved-namespace`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-reserved-namespace) |
| Other reserved root | Any other root in the list below, except `app` and `user`, is refused `400 validation_error`. | [`types/id-reserved-scope-root`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesid-reserved-scope-root) |

## Fields

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Keys | A field definition takes `type`, `description`, `required`, `enum_values`, `items_type`, `format`, `searchable`, `maxLength` and `maxItems`. Any other key, such as `minimum`, is refused `400 invalid_schema`. | [`types/unknown-key`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesunknown-key) |
| Kind | `type` is one of the [field kinds](/catalog/field-kinds). An unknown `type` or `format` is refused `400 invalid_schema`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| `enum` | Needs `enum_values`, a list of at least one string. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| `array` | Needs `items_type`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| `maxLength`, `maxItems` | A whole number of at least 1. `maxLength` applies to `string` and `enum`, `maxItems` to `array`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| Array elements | Each element must be a value of the field's `items_type`. A write that leaves a wrong element is refused `400 invalid_properties`, and `details.errors` names the field and position, as `names.1`. | [`types/array-items-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesarray-items-refused) |
| Unnamed `items_type` | An `items_type` that isn't a field kind leaves the elements unchecked. | [`types/array-items-unnamed`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesarray-items-unnamed) |
| Name | A name in the reserved field names below is refused `400 property_shadows_field`. | [`types/field-shadows-item`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-shadows-item) |
| Thumbnail count | At most one `thumbnail` field, counting inherited ones. A second is refused `400 invalid_schema`. | [`types/thumbnail-one`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-one) |
| Thumbnail name | Not `title`, `body`, `description` or `name`. An array's `items_type` can't be `thumbnail`. Refused `400 invalid_schema`. | [`types/thumbnail-name`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-name) |
| `title_field`, `body_field` | Must name a field the type declares or inherits. Refused `400 invalid_schema`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| Thumbnail as hint | Neither `title_field` nor `body_field` can name a `thumbnail` field. Refused `400 invalid_schema`. | [`types/thumbnail-hint`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesthumbnail-hint) |

## Parent and inheritance

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| `parent` | Names a registered type. Anything else is refused `400 validation_error`. | [`types/parent-unknown`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-unknown) |
| Depth | No loop, and at most ten ancestors. | [`types/parent-chain`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-chain) |
| Subtype may | Add fields, redeclare an inherited field unchanged or with a new `description`, and make an inherited field required. | [`types/child-adds`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeschild-adds) |
| Subtype may not | Change an inherited field's `type`, `format`, `items_type`, `searchable`, `maxLength`, `maxItems` or `enum_values`, or make a required field optional. Refused `400 inheritance_violation`. | [`types/child-shape`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeschild-shape) |
| Write access | A new `parent` that Marfa doesn't ship needs write on that type; keeping one doesn't. Refused `403 type_not_permitted`. | [`types/parent-reach`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesparent-reach) |

### Compatible with

`compatible_with` names a type that yours is readable as, without inheriting from it.

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Required fields | Yours requires every field the target requires. | [`types/compatible-with`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) |
| Field kinds | Each target field that yours declares or inherits has the same kind. A `string` target field also accepts `url`, `email`, `datetime`, `date`, `thumbnail` or `enum`, and a `number` accepts `integer`. | [`types/compatible-with`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) |
| Arrays and enums | An `array` has the same `items_type`. An `enum` takes values from the target's. | [`types/compatible-with`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) |
| Format | Where both name a `format`, it is the same one. | [`types/compatible-with`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with) |
| Refusal | A claim that doesn't hold, or names an unregistered type, is refused `422 compatible_with_violation`. | [`types/compatible-with-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-refused) |
| Later changes | A replacement or deletion that breaks another type's claim is refused the same way, and `details.dependent_type_ids` names the claimants. | [`types/compatible-with-preserved`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-preserved) |
| Write access | A new target that Marfa doesn't ship needs write on it; keeping one doesn't. Refused `403 type_not_permitted`. | [`types/compatible-with-reach`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typescompatible-with-reach) |

## Roles

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| `roles` | Takes `container` alone. Any other role is refused `400 invalid_schema`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| `container` | The type can be the target of an [`in-collection`](/catalog/edges#in-collection) edge. | [`edges/collection-target`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/edges.md#edgescollection-target) |

## Merge policy

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Shape | `fields` maps a field the type declares or inherits to a strategy. `default` covers the rest, and is `last_writer_wins` when left out. | [`types/merge-policy`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesmerge-policy) |
| Refusal | A field the type doesn't declare, or another strategy, is refused `400 invalid_schema`. | [`types/merge-policy-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesmerge-policy-refused) |

| Strategy | When a later write resolves a collision on the field | Contract |
| --- | --- | --- |
| `last_writer_wins` | The item takes the later writer's value. | [`versions/auto-last-writer`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md#versionsauto-last-writer) |
| `keep_both_copies` | The item keeps its value, and the later writer's value goes to a new item tagged `conflicted-copy`. | [`versions/copy-written`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md#versionscopy-written) |

## Retention policy

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Key | Only `feed_days`. | [`types/unknown-key`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesunknown-key) |
| `feed_days` of 1 to 36500 | A whole number of days. The `feed-expiry` [housekeeping job](/guides/housekeeping) moves the type's feed items to the bin once more than that many days have passed since they arrived. | [`types/retention-policy-values`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-values) |
| Counting | From the item's `created_at`. A natural-key upsert keeps it, so a refresh doesn't restart the count. | [`housekeeping/feed-expiry-arrival`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/housekeeping.md#housekeepingfeed-expiry-arrival) |
| `feed_days` of `null` | The type keeps its feed items, even when a parent sets a window. | [`types/retention-policy-merge`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-merge) |
| `feed_days` left out | The type takes its parent's window. Where no type in the chain sets one, it keeps its feed items. | [`types/retention-policy-merge`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-merge) |
| Other value | Refused `400 invalid_schema`. | [`types/retention-policy-values`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesretention-policy-values) |
| Reading | `GET /types/{id}` shows the window after inheritance. `GET /types` shows only the window the type declares. | [`types/list-declared-policy`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typeslist-declared-policy) |

The rules behind this page are in the [types](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md), [versions](https://github.com/withmarfa/marfa/blob/main/conformance/spec/versions.md), [edges](https://github.com/withmarfa/marfa/blob/main/conformance/spec/edges.md) and [housekeeping](https://github.com/withmarfa/marfa/blob/main/conformance/spec/housekeeping.md) chapters of the contract.
