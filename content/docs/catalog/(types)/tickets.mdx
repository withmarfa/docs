```bash
marfa plugins install tickets
```

## Inherited fields

A ticket has the fields of [Task](/catalog/task#fields): `title`, `description`, `body`, `status`, `priority`, `assignees`, `due_at`, `starts_at`, `completed_at`, `place`, `precision`, `url`, `notes` and `recurrence`.

## Edges

The plugin adds no edge type. Its guidance uses [`parent-of`](/catalog/edges/parent-of) and [`derived-from`](/catalog/edges/derived-from).
