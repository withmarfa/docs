[Save a list as a view](/guides/save-a-view) uses the view operations that write these settings. No item operation writes a view: each one refuses a `system.*` type with `403 type_not_permitted` ([`items/system-types`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemssystem-types)).
