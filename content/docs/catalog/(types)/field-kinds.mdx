---
title: Field kinds
description: "What a type's field definition takes, the kinds of value a field can hold, and what Marfa accepts for each."
---

Each field of a type holds one kind of value, named by its `type`. **Marfa refuses a definition that breaks a rule here with `400 invalid_schema`**, naming the key, and **a value the field doesn't accept with `400 invalid_properties`**, naming the field in `details.errors`. A device checks whole numbers, URLs, ranges, currency codes and list entries offline, and queues nothing it refuses.

## Definition

A field definition takes these keys, and nothing else:

| Key | What it holds |
| --- | --- |
| `type` | One of the kinds below. Required. |
| `label` | The field's name for people, at most 100 characters. Left out, `GET /types/{id}` answers one made from the field name, so `due_at` shows as `Due At`. `GET /types` lists only declared labels. |
| `description` | What the field holds. |
| `required` | `true` when every item of the type must hold it. |
| `enum_values` | For an `enum`, the values it takes: a list of at least one string. |
| `status_values` | For a `status`, its words. See [Status words](#status-words). |
| `items_type` | For an `array`, the kind of its elements. Required. A name that isn't a kind leaves the elements unchecked. |
| `items_fields` | For an `array` of `object`, the members of each entry. See [Lists of entries](#lists-of-entries). |
| `format` | A refinement of the kind. See [Formats](#formats). |
| `searchable` | `false` leaves the field out of full-text search. |
| `maxLength` | For a `string` or `enum`, the most characters. A whole number of at least 1. |
| `maxItems` | For an `array`, the most elements. A whole number of at least 1. |
| `minimum`, `maximum` | For a `number` or `integer`, the range. See [Ranges](#ranges). |

**A type holds at most one `thumbnail` field**, counting inherited ones. It can't be named `title`, `body`, `description` or `name`, or be an array's `items_type`. [Type rules](/catalog/type-rules#parent-and-inheritance) says what a subtype may change.

## Kinds

| Kind | Holds |
| --- | --- |
| `string` | Text of up to `maxLength` UTF-16 code units, or 100,000 where the field sets none. It can't hold U+0000. |
| `number` | A number, within the field's range. A whole number must be written in the shortest digits of its 64-bit float, so Marfa serves it back unchanged: `1500000000000000001` and `-0` are refused. Send a whole number that must keep every digit as a `string`. |
| `integer` | A whole number, written the same way, within the field's range. |
| `boolean` | `true` or `false`. |
| `url` | An absolute URL that the WHATWG URL Standard accepts once whitespace is trimmed from both ends. Marfa stores it without that whitespace and without tab, line feed and carriage return characters. |
| `email` | An email address. |
| `datetime` | A date and time with a zone, such as `2026-03-01T09:30:00Z`, or a date alone, as `YYYY-MM-DD`. A time with no zone is refused. |
| `date` | A date alone, as `YYYY-MM-DD`. A date with a time is refused. |
| `enum` | One of the field's `enum_values`. |
| `status` | One of the field's status words. |
| `array` | A list. Each element is of the kind `items_type` names, or an entry its `items_fields` take. |
| `object` | A JSON object. |
| `thumbnail` | A PNG, JPEG or WebP data URI that decodes to at most 16 KiB. |

The rule on whole numbers holds at any depth, and also in an edge's `properties` and an extension's data. A bulk write that breaks it is refused whole, and `details.index` gives the entry's position. A wrong element in an array names its position, as `names.1`.

## Status words

A `status` field says where an item stands, in words the type chooses. Each word belongs to one of four groups that every type shares: `not_started`, `in_progress`, `completed` and `canceled`. An app can then group and filter any type's items without knowing its words, and a filter selects by group with the `status_group` term.

- **`status_values`** is a list of `{ "value": "<word>", "group": "<group>" }`. A word is a lowercase letter, then up to 63 lowercase letters, digits or underscores, and appears once.
- **A type has at most one status field**, and an `array` can't hold status words. No type can add, rename or remove a group.
- **A write that changes the field to a word the type doesn't declare is refused**, as is a create that names one, or a move to another type. An item that holds a word its type no longer declares keeps it, and stays editable.

[Type rules](/catalog/type-rules#status-words) says how a subtype adds words.

## Ranges

`minimum` and `maximum` bound a `number` or `integer` field, or an entry member of those kinds. Both include the number they name, so a range of 1 to 5 takes 1 and 5. On an `integer` they must be whole, and a `minimum` above the `maximum` is refused.

## Lists of entries

`items_fields` gives each entry of an `array` of `object` its members, such as an email and a label. A member is a `string`, `email`, `url`, `enum`, `boolean`, `integer`, `number`, `date` or `datetime`, and takes `type`, `label`, `description`, `required`, `enum_values`, `format`, `maxLength`, `minimum` and `maximum`.

An entry holds at least one member, only declared ones, and every required one. A refused entry names its position and member, as `emails.1.value`.

## Formats

A field's `format` refines its kind:

| Format on the field | What Marfa does |
| --- | --- |
| `url`, `email`, `datetime`, `date` or `thumbnail` on a `string` field | Stores the field as that kind. An array of strings takes any of the first four, and becomes an array of that kind. |
| A format that names the field's own kind, such as `url` on a `url` field | Stores the field without the `format`. |
| `currency` on a `string` field | Takes three capital letters from A to Z, such as `EUR`, whether or not ISO 4217 assigns the code. The field can't set `maxLength`. |
| `bcp47`, `iso3166` or `phone` on a `string` field | Keeps the format as a label, for a language tag, a country code or a phone number an app can call. Marfa doesn't check the value. |
| Any other format, or one of these on a kind the rows above don't allow | Refuses the type with `400 invalid_schema`. |
