A message is a row of the `messages` table, never an item. [Tables](/build/tables) says how rows are written. A message people read on its own, such as an email, is a [`core.message`](/catalog/message) item.

## Example

```json
{
  "type": "core.conversation",
  "properties": {
    "title": "Planning the Lisbon trip"
  }
}
```

One row of its `messages` table:

```json
{
  "author": "Ana",
  "text": "Which week works for Lisbon?",
  "sent_at": "2026-04-01T09:12:00Z"
}
```
