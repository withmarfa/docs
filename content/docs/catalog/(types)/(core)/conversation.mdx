<include cwd>src/generated/catalog/core.conversation.md</include>

A message is a row, never an item, so it has no version, tags or edges of its own. Rows are written with [`writeTableRows`](/reference/api/tables/writeTableRows) or `marfa rows`, as [Tables](/build/tables) explains. A message people read on its own, such as an email, is a [`core.message`](/catalog/message) item instead.

## Example

```json
{
  "type": "core.conversation",
  "properties": {
    "title": "Planning the Lisbon trip"
  }
}
```

One row of its `messages` table:

```json
{
  "author": "Ana",
  "text": "Which week works for Lisbon?",
  "sent_at": "2026-04-01T09:12:00Z"
}
```
