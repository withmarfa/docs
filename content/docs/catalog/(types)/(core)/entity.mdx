## Contact lists

`emails`, `phones` and `addresses` are lists whose first entry is the main one. An entity has no `email`, `phone` or `place` field: Marfa keeps a value under one of those names as an undeclared property unless [strict mode](https://github.com/withmarfa/marfa/blob/v0.0.90/conformance/spec/types.md#typesstrict-mode) names the type, and an app reading the lists never sees it. An app finds the person behind an [event's](/catalog/event) attendee or a [task's](/catalog/task) assignee by matching the email to a value in `emails`.

## Example

```json
{
  "type": "core.entity.person",
  "properties": {
    "name": "Priya Raman",
    "given_name": "Priya",
    "family_name": "Raman",
    "emails": [{ "value": "priya.raman@example.com", "label": "work" }],
    "phones": [{ "value": "+442079460958", "label": "work" }],
    "organization": "Harbour Press",
    "job_title": "Managing editor"
  }
}
```
