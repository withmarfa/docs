## Contact lists

A person or an organization holds its email addresses, phone numbers and postal addresses in `emails`, `phones` and `addresses`, and the first entry of each is the main one. An app finds the person behind an [event's](/catalog/event) attendee or a [task's](/catalog/task) assignee by matching the email to a value in `emails`.

An entity has no `email`, `phone` or `place` field. Marfa treats a value written under one of those names as any undeclared property, and an app that reads the lists doesn't see it. A place also has its own address fields beside `addresses`.

## Example

```json
{
  "type": "core.entity.person",
  "properties": {
    "name": "Priya Raman",
    "given_name": "Priya",
    "family_name": "Raman",
    "emails": [{ "value": "priya.raman@example.com", "label": "work" }],
    "phones": [{ "value": "+44 20 7946 0958", "label": "work" }],
    "organization": "Harbour Press",
    "job_title": "Managing editor"
  }
}
```
