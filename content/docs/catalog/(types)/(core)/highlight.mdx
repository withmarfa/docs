## Name

A highlight's passage is never its name. With no `title`, a highlight is named after the item it's an [`excerpt-of`](/catalog/edges/excerpt-of), and with none, `Untitled`. [Display hints](/catalog/type-definition#display-hints) has the rule.

## Example

```json
{
  "type": "core.highlight",
  "properties": {
    "text": "A type is a promise that every app reading an item can rely on.",
    "note": "Use this line in the intro.",
    "color": "yellow",
    "locator_type": "page",
    "start_location": "112"
  }
}
```
