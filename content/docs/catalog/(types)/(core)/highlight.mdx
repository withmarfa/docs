## Name

A highlight's passage is its text, never its name. A highlight with no `title` is named after the item it's an [`excerpt-of`](/catalog/edges#excerpt-of), such as "Excerpt from Thinking, Fast and Slow", so several highlights from one book share a name. With no such item, the server names it `Untitled`. [Names and previews](/catalog/display-hints#names-and-previews) has the rule.

## Example

```json
{
  "type": "core.highlight",
  "properties": {
    "text": "A type is a promise that every app reading an item can rely on.",
    "note": "Use this line in the intro.",
    "color": "yellow",
    "locator_type": "page",
    "start_location": "112"
  }
}
```
