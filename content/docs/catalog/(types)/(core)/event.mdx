## Attendees

An `attendees` entry holds a `name`, an `email` or both, and the person's `response`, and no item ID. A bad entry is refused `400 invalid_properties`, naming its position and member, as `attendees.0.response`.

## Example

```json
{
  "type": "core.event",
  "properties": {
    "title": "Design review",
    "description": "Walk through the new onboarding flow.",
    "starts_at": "2026-11-03T14:00:00Z",
    "ends_at": "2026-11-03T15:00:00Z",
    "timezone": "Europe/London",
    "place": "Studio 2",
    "attendees": [
      { "name": "Priya Raman", "email": "priya.raman@example.com", "response": "accepted" },
      { "email": "sam@example.com", "response": "needs_action" }
    ]
  }
}
```
