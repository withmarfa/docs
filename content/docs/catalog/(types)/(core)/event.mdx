## Attendees

`attendees` lists the people invited, each by `name`, `email` or both, with their `response`: `needs_action` before they reply, then `accepted`, `declined` or `tentative`. An entry holds no item ID: an app finds the person by matching the email to a value in a [person's](/catalog/entity) `emails`. A bad entry is refused `400 invalid_properties`, naming its position and member, as `attendees.0.response`.

## Example

```json
{
  "type": "core.event",
  "properties": {
    "title": "Design review",
    "description": "Walk through the new onboarding flow.",
    "starts_at": "2026-11-03T14:00:00Z",
    "ends_at": "2026-11-03T15:00:00Z",
    "timezone": "Europe/London",
    "place": "Studio 2",
    "attendees": [
      { "name": "Priya Raman", "email": "priya.raman@example.com", "response": "accepted" },
      { "email": "sam@example.com", "response": "needs_action" }
    ]
  }
}
```
