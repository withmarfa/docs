## Repeats and assignees

- **A repeating task holds `recurrence`**, in the same RFC 5545 lines as an [event](/catalog/event). The series starts at `due_at`, or at `starts_at` when there's no `due_at`, and runs in UTC. A rule on a task with neither is refused. Marfa checks and keeps the rule but doesn't unfold it, so [list event occurrences](/api-reference/items/listOccurrences) answers events only.
- **`assignees`** names each person by `name`, `email` or both. An entry holds no item ID: an app finds the person by matching the email to a value in a [person's](/catalog/entity) `emails`. A `response` is refused.

## Example

```json
{
  "type": "core.task",
  "properties": {
    "title": "Water the office plants",
    "due_at": "2026-11-06T09:00:00Z",
    "status": "not_started",
    "priority": "medium",
    "recurrence": ["RRULE:FREQ=WEEKLY"],
    "assignees": [{ "name": "Priya Raman", "email": "priya.raman@example.com" }]
  }
}
```
