## Repeats and assignees

- **A repeating task holds `recurrence`,** in the RFC 5545 lines of an [event](/catalog/event). The series starts at `due_at`, or at `starts_at` without one, and a rule on a task with neither is refused. Marfa checks the rule and doesn't unfold it, so [list event occurrences](/reference/api/items/listOccurrences) answers events only.
- **An `assignees` entry** holds a `name`, an `email` or both, and no item ID. A `response` is refused.

## Example

```json
{
  "type": "core.task",
  "properties": {
    "title": "Water the office plants",
    "due_at": "2026-11-06T09:00:00Z",
    "status": "not_started",
    "priority": "medium",
    "recurrence": ["RRULE:FREQ=WEEKLY"],
    "assignees": [{ "name": "Priya Raman", "email": "priya.raman@example.com" }]
  }
}
```
