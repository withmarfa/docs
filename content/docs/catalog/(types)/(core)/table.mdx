<include cwd>src/generated/catalog/core.table.md</include>

The item holds one table, named `table`, whose columns are its `columns` property, keyed by column name. [Field kinds](/catalog/field-kinds#columns) lists the keys a column takes. Its rows are written to `table` with [`writeTableRows`](/reference/api/tables/writeTableRows) or `marfa rows`, as [Tables](/build/tables) explains.

## Example

```json
{
  "type": "core.table",
  "properties": {
    "title": "Trip budget",
    "description": "What the Lisbon trip costs, by day.",
    "columns": {
      "day": { "type": "date", "label": "Day", "required": true },
      "item": { "type": "string", "label": "What", "searchable": true },
      "category": { "type": "enum", "label": "Category", "enum_values": ["travel", "food", "stay"] },
      "amount": { "type": "number", "label": "Amount", "minimum": 0, "adds_up": "sum" }
    }
  }
}
```
