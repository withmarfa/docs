The item holds one table, `table`, whose columns are its `columns` property. [Field kinds](/catalog/field-kinds#columns) lists the keys a column takes, and [Tables](/build/tables) says how rows are written.

## Example

```json
{
  "type": "core.table",
  "properties": {
    "title": "Trip budget",
    "description": "What the Lisbon trip costs, by day.",
    "columns": {
      "day": { "type": "date", "label": "Day", "required": true },
      "item": { "type": "string", "label": "What", "searchable": true },
      "category": { "type": "enum", "label": "Category", "enum_values": ["travel", "food", "stay"] },
      "amount": { "type": "number", "label": "Amount", "minimum": 0, "adds_up": "sum" }
    }
  }
}
```
