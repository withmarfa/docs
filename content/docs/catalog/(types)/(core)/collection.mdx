title: Collection

identifier: core.collection
---

## Example

```json
{
  "type": "core.collection",
  "properties": {
    "title": "Kitchen renovation",
    "description": "Quotes, sketches and the tasks still to book."
  }
}
```

An item joins the collection through an [`in-collection`](/catalog/edges#in-collection) edge from the item to the collection, with an optional `position`:

```json
{
  "source_id": "01a12313-ad0e-71cd-99b4-7a176c5a9f18",
  "target_id": "01a12314-0b52-7c41-8e0f-2d6f1a3b9c07",
  "edge_type": "in-collection",
  "properties": { "position": 1 }
}
```

A container, such as another collection or an album, can't be a member. An item can be in any number of collections, and deleting a collection leaves its members in place.
