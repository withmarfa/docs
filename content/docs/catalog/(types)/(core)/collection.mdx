## Example

```json
{
  "type": "core.collection",
  "properties": {
    "title": "Kitchen renovation",
    "description": "Quotes, sketches and the tasks still to book."
  }
}
```

The [`in-collection`](/catalog/edges/in-collection) edge, from the item to the collection, makes an item a member, unless its type plays the `container` role.
