## Progress and rating

Every media type, games included, inherits two fields for where you are with a work and what you think of it:

- **`progress`** is a [status field](/catalog/field-kinds#status-words) whose group a `status_group` filter reads on any media type. A series also holds `status`, a separate field that says whether it's still producing episodes.
- **`rating`** is a whole number from 1 to 5. A fraction, or a number outside the range, is refused `400 invalid_properties`.

Marfa doesn't compare a game's `min_players` with its `max_players`.

## Example

```json
{
  "type": "core.media.game",
  "properties": {
    "title": "Harbour Lights",
    "author": "Tamsin Okafor",
    "platforms": ["Tabletop"],
    "min_players": 2,
    "max_players": 5,
    "progress": "finished",
    "rating": 4
  }
}
```
