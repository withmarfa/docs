## Progress and rating

- **`progress`** is a [status field](/catalog/field-kinds#status-words) that every media type inherits, so a `status_group` filter reads it on any of them. A series also holds `status`, a separate field for whether it's still producing episodes.
- **`rating`** is a whole number from 1 to 5. Anything else is refused `400 invalid_properties`.

Marfa doesn't compare a game's `min_players` with its `max_players`.

## Example

```json
{
  "type": "core.media.game",
  "properties": {
    "title": "Harbour Lights",
    "author": "Tamsin Okafor",
    "platforms": ["Tabletop"],
    "min_players": 2,
    "max_players": 5,
    "progress": "finished",
    "rating": 4
  }
}
```
