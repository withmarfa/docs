## Example

```json
{
  "type": "core.file.image",
  "properties": {
    "blob_ref": "sha256:8fb0362f95275f0060623967b2b3267b1c66c7ecfeaa314fc7a44301903ffec3",
    "mime_type": "image/jpeg",
    "title": "allotment-in-june.jpg",
    "description": "The south bed after the first planting.",
    "width": 4032,
    "height": 3024
  }
}
```

[Files](/build/files#a-blob-and-the-item-that-names-it) shows how to upload the bytes and get a `blob_ref`.
