---
title: System types
description: The two types Marfa writes for itself, a connection and a folder.
---

Marfa writes `system.connection` when you approve an app's consent or device sign-in, and `system.folder` through the folder operations that [Sync a folder](/guides/sync-a-folder) uses. No item operation writes either: it refuses a `system.*` type with `403 type_not_permitted` ([`items/system-types`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemssystem-types)).
