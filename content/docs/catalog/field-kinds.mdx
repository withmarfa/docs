---
title: Field kinds
description: The kinds of value a type's field can hold, and what Marfa accepts for each.
---

Each field of a type holds one kind of value, named by its `type`. **A value Marfa doesn't accept for its kind is refused `400 invalid_properties`**, and `details.errors` names the field. A device judges whole numbers and URLs the same way offline, and queues nothing it refuses.

## Kinds

| Kind | Holds |
| --- | --- |
| `string` | Text of up to `maxLength` UTF-16 code units, or 100,000 where the field sets none. It can't hold U+0000. |
| `number` | A number. A whole number must be written in the shortest digits of its 64-bit float, so Marfa serves it back unchanged: `1500000000000000001` and `-0` are refused. Send a whole number that must keep every digit as a `string`. |
| `integer` | A whole number, written the same way. |
| `boolean` | `true` or `false`. |
| `url` | An absolute URL that the WHATWG URL Standard accepts once whitespace is trimmed from both ends. Marfa stores it without that whitespace. |
| `email` | An email address. |
| `datetime` | A date and time with a zone, such as `2026-03-01T09:30:00Z`, or a date alone, as `YYYY-MM-DD`. A time with no zone is refused. |
| `date` | A date alone, as `YYYY-MM-DD`. A date with a time is refused. |
| `enum` | One of the field's `enum_values`. |
| `array` | A list. `items_type` names the kind of its elements, and `maxItems` caps their number. |
| `object` | A JSON object. |
| `thumbnail` | A PNG, JPEG or WebP data URI that decodes to at most 16 KiB. |

The rule on whole numbers holds at any depth, and also in an edge's `properties` and an extension's data. A bulk write that breaks it is refused whole, and `details.index` gives the entry's position.

## Formats

A field's `format` refines its kind:

| Format on the field | What Marfa does |
| --- | --- |
| `url`, `email`, `datetime`, `date` or `thumbnail` on a `string` field | Stores the field as that kind. An array of strings takes any of the first four, and becomes an array of that kind. |
| A format that names the field's own kind, such as `url` on a `url` field | Stores the field without the `format`. |
| `bcp47` or `iso3166` on a `string` field | Keeps the format as a label, for a language tag (as on `language`) or a country code (as on `country`). Marfa doesn't check the value. |
| Any of these on another kind, or `thumbnail` on an array | Refuses the type with `400 invalid_schema`. |

The rules behind this page are in the [items](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md), [types](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md) and [device](https://github.com/withmarfa/marfa/blob/main/conformance/spec/device.md) chapters of the contract, including how Marfa reads a URL's host.
