---
title: Field kinds
description: The kinds of value a type's field can hold.
---

| Kind        | Holds                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `string`    | Text, up to the field's `maxLength` in UTF-16 code units, or 100,000 where it sets none.                                       |
| `number`    | A number.                                                                                                                      |
| `integer`   | A whole number.                                                                                                                |
| `boolean`   | `true` or `false`.                                                                                                             |
| `url`       | A URL.                                                                                                                         |
| `email`     | An email address.                                                                                                              |
| `datetime`  | A date as `YYYY-MM-DD`, or a date and time with a zone, such as `2026-03-01T09:30:00Z`.                                        |
| `date`      | A calendar date as `YYYY-MM-DD`.                                                                                               |
| `enum`      | One of the field's `enum_values`.                                                                                              |
| `array`     | A list. The field's `items_type` names the kind of its elements, and Marfa refuses a write whose elements aren't of that kind. |
| `object`    | A JSON object.                                                                                                                 |
| `thumbnail` | A small image as a PNG, JPEG or WebP data URI that decodes to at most 16 KiB.                                                  |

A `string` field can also name a `format` that only labels it: `bcp47` for a language tag, as on `language`, and `iso3166` for a country code, as on `country`.
