---
title: Field kinds
description: The kinds of value a type's field can hold.
---

| Kind        | Holds                                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `string`    | Text, up to the field's `maxLength` in UTF-16 code units, or 100,000 where it sets none.                                       |
| `number`    | A number. A whole number must be one Marfa serves back with the same digits, as the notes below say.                           |
| `integer`   | A whole number, with the same rule on its digits.                                                                              |
| `boolean`   | `true` or `false`.                                                                                                             |
| `url`       | An absolute URL that the WHATWG URL Standard accepts, as the notes below say.                                                  |
| `email`     | An email address.                                                                                                              |
| `datetime`  | A date as `YYYY-MM-DD`, or a date and time with a zone, such as `2026-03-01T09:30:00Z`.                                        |
| `date`      | A calendar date as `YYYY-MM-DD`.                                                                                               |
| `enum`      | One of the field's `enum_values`.                                                                                              |
| `array`     | A list. The field's `items_type` names the kind of its elements, and Marfa refuses a write whose elements aren't of that kind. |
| `object`    | A JSON object.                                                                                                                 |
| `thumbnail` | A small image as a PNG, JPEG or WebP data URI that decodes to at most 16 KiB.                                                  |

A `string` field can also name a `format` that only labels it: `bcp47` for a language tag, as on `language`, and `iso3166` for a country code, as on `country`.

**Marfa refuses a whole number it can't serve back with the same digits.** It holds a number as a 64-bit float and serves it in the shortest digits that name that float, as JavaScript's `Number.prototype.toString` writes them. A write that names `1500000000000000001`, `1152921504606846976` (2^60) or `-0` is refused `400 invalid_properties`, because Marfa would serve them as `1500000000000000000`, `1152921504606847000` and `0`. `details.errors` names the value in `field`, such as `list.1`, with the message `Must be a whole number that Marfa serves back with the same digits, not <digits>, which it serves as <served>. Send it as a string.` A bulk write is refused whole, and `details.index` gives the entry's position. A number Marfa serves with the digits sent, such as `1152921504606847000`, and a number with a fraction or an exponent are taken. **The rule covers every property value at any depth**, an edge's `properties` and an extension's data too, and a device refuses the same numbers before it queues the write. A value that must keep every digit goes in a `string` field.

**Marfa judges a `url` value as the WHATWG URL Standard does.** It removes whitespace from both ends first, the whitespace that JavaScript's `String.prototype.trim` removes except U+0085, and U+FEFF. It then accepts the value where the standard parses it as an absolute URL, whichever Node.js version runs the server. A host that is ASCII after percent-decoding is taken whatever its labels hold, so `http://xn--` is a URL. A host with other characters must be valid IDNA, and a host with a forbidden domain code point, or a last label that is a number where the host isn't a valid IPv4 address, is refused `400 invalid_properties`. Marfa stores the value without the whitespace it removed and without any tab, line feed or carriage return. A device judges the same way, with one exception: it refuses a host that holds a code point its own IDNA tables don't assign, which the server takes.
