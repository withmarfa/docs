---
title: Field kinds
description: The kinds of value a type's field can hold, and what Marfa accepts for each.
---

## Kinds

| Kind | Holds | Contract |
| --- | --- | --- |
| `string` | Text of up to `maxLength` UTF-16 code units, or 100,000 where the field sets none. No U+0000. | [`items/property-length-cap`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-length-cap) |
| `number` | A number. A whole number must be one Marfa serves back with the same digits (see Values). | [`items/property-number-exact`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-number-exact) |
| `integer` | A whole number, with the same rule on its digits. | [`items/property-number-exact`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-number-exact) |
| `boolean` | `true` or `false`. | [`items/property-invalid`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-invalid) |
| `url` | An absolute URL that the WHATWG URL Standard accepts (see Values). | [`types/url-value`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-value) |
| `email` | An email address. | [`items/property-invalid`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-invalid) |
| `datetime` | A date as `YYYY-MM-DD`, or a date and time with a zone, such as `2026-03-01T09:30:00Z`. | [`types/datetime-value`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesdatetime-value) |
| `date` | A calendar date as `YYYY-MM-DD`, with no time. | [`types/datetime-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesdatetime-refused) |
| `enum` | One of the field's `enum_values`. | [`types/field-grammar`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesfield-grammar) |
| `array` | A list. `items_type` names the kind of its elements, and `maxItems` caps their number. | [`types/array-items`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesarray-items) |
| `object` | A JSON object. | [`items/property-invalid`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-invalid) |
| `thumbnail` | A PNG, JPEG or WebP data URI that decodes to at most 16 KiB. | [`items/thumbnail-format`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsthumbnail-format) |

A value of the wrong shape is refused `400 invalid_properties`, and `details.errors` names the field.

## Formats

| Format | What Marfa does | Contract |
| --- | --- | --- |
| `url`, `email`, `datetime`, `date`, `thumbnail` | On a `string` field, stores the field as that kind. On an array of strings, stores an array of that kind, except for `thumbnail`. | [`types/format-collapses`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesformat-collapses) |
| `bcp47`, `iso3166` | Keeps the format as a label on a `string` field: `bcp47` for a language tag, as on `language`, and `iso3166` for a country code, as on `country`. Marfa doesn't judge the value. | [`types/format-string-only`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesformat-string-only) |
| On another kind | Refuses a `format` on a field of another kind with `400 invalid_schema`. | [`types/format-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesformat-refused) |

## Values

| Rule | Marfa allows or refuses | Contract |
| --- | --- | --- |
| Exact whole numbers | A whole number must be written in the shortest digits of its 64-bit float. `1500000000000000001`, 2^60 (`1152921504606846976`) and `-0` are refused `400 invalid_properties`. Send a value that must keep every digit as a `string`. | [`items/property-number-exact`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-number-exact) |
| Where it applies | At any depth, including an edge's `properties` and an extension's data. A bulk write is refused whole, and `details.index` gives the entry's position. | [`items/property-number-exact-bulk`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-number-exact-bulk) |
| Numbers Marfa takes | A whole number in its shortest digits, such as `1152921504606847000`, and a number with a fraction or an exponent. | [`items/property-number-kept`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md#itemsproperty-number-kept) |
| URL trimming | Marfa trims whitespace from both ends, as JavaScript's `String.prototype.trim` does, then parses the value as an absolute URL. | [`types/url-value`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-value) |
| URL storage | Marfa stores the URL without the trimmed whitespace and without tab, line feed and carriage return characters. | [`types/url-stored`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-stored) |
| ASCII host | On a special scheme such as `http`, a host that is ASCII after percent-decoding is taken whatever its labels hold, so `http://xn--` is a URL. | [`types/url-punycode`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-punycode) |
| Non-ASCII host | Must be valid IDNA. `http://bücher.xn--` is refused `400 invalid_properties`. | [`types/url-idna`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-idna) |
| Forbidden host | A forbidden domain code point, or a last label that is a number where the host isn't a valid IPv4 address, is refused `400 invalid_properties`. | [`types/url-host-refused`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md#typesurl-host-refused) |
| On a device | A device applies the same rules offline. It also refuses a special-scheme URL whose host holds a code point its IDNA tables leave unassigned. | [`device/url-idna-unassigned`](https://github.com/withmarfa/marfa/blob/main/conformance/spec/device.md#deviceurl-idna-unassigned) |

The rules behind this page are in the [items](https://github.com/withmarfa/marfa/blob/main/conformance/spec/items.md), [types](https://github.com/withmarfa/marfa/blob/main/conformance/spec/types.md) and [device](https://github.com/withmarfa/marfa/blob/main/conformance/spec/device.md) chapters of the contract.
