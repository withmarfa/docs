`GET /export` streams a tenant's items, edges, metadata, extensions, and blob references in one pass. Use it for backups, migrations between Marfa instances, and bulk extraction into an external store. The response streams until the filter is exhausted, so a large tenant exports without buffering the whole dataset in memory.

## Formats

Two output formats, selected with `format`:

- **NDJSON** (default) — one JSON record per line, streamed as `application/x-ndjson`. Each line pairs an item with its metadata. Suited to piping into a downstream loader.
- **Archive** — `format=archive` returns a gzipped tar (downloaded as `marfa-export-<date>.tar.gz`): items, edges, metadata, extensions, and the referenced blobs bundled together. This is the format `POST /admin/restore-archive` ingests. See [Archive restore](/guides/querying/bulk-operations#archive-restore).

The full record shape for each format lives in the API reference.

## Scope and filters

Export is tenant-scoped — it returns only what the calling credential can read, the same visibility rule as [`GET /items`](/guides/querying/search-and-query). The same narrowing parameters apply:

- `type` — a single type identifier (subtypes included via inheritance).
- `state` — `active`, `archived`, or `trashed`.
- `source` — items stamped with a given source credential.
- `since` and `until` — bound the export by the item's effective time, as in [Search and query](/guides/querying/search-and-query).

<Callout type="info">
  Platform admins (a credential with no tenant) must pass `target_tenant_id` to scope the export to one tenant. Without it, a hosted multi-tenant export is rejected; on a single-tenant self-host the parameter is unnecessary.
</Callout>

## Auditing

Every export is recorded in the [audit log](/guides/operations/audit) as an `export.tenant` action before streaming starts, capturing the format and the resolved tenant scope. A platform-admin export that runs without a `target_tenant_id` is flagged in the audit details so operators can spot an accidental unscoped extraction.
