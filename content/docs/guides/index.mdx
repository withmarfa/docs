The guides explain how Marfa works and how to build on it — the data model first, then schema, identity, querying, real-time, connections, and the cross-cutting operational concerns. Wire shapes (request and response bodies, status codes) live in the [API reference](/api-reference), alongside the auth contract, error catalog, and rate limits; these pages cover the semantics the spec can't encode.
