A working copy answers reads from its store with no request and **queues every write,** which shows at once and reaches the server at the next [drain](/reference/swift-sdk/working-copy#the-queue). Each write returns its `QueuedWrite`. [Write in a working copy](/build/write-in-a-working-copy) explains the model.

## Read items

| Call | Answers |
| --- | --- |
| `items.list(_ ListFilters, sort:)` | `Rows<Item>` the filters select. |
| `items.get(_ id)` | `Item?`: `nil` for an item in the bin or not held. **Throws `hydrationIncomplete`** while a hydration fills the copy. |
| `items.get(_ ids, includingBin:)` | `Rows<Item>` in the order named, from one snapshot, `.partial` during a hydration. |
| `copy.search(_ text, filters:limit:)` | `Rows<SearchHit>` with `item`, `score` and `snippet`. `limit` defaults to 20. |
| `items.links(in:)`, `items.linkCandidates(of:in:)`, `linkParts(in:)` | Each link and embed in a body and what it names, the held items a `[[link]]` being typed could name, and a text's links with their UTF-16 ranges. |
| `items.displays(of:)`, `items.displays(for:)` | An `ItemDisplay` each: `name`, `nil` where the server says "Untitled", and a `preview` of at most 240 characters. |
| `items.thumbnail(_:)` | The held row's `Thumbnail`. |
| `items.conflictedCopies(of:)`, `items.original(ofConflictedCopy:)` | The two ends of a `derived-from` edge. |
| `copy.counts(of:_ Counted)` | An `ItemCount` for each ID. |

An `Item` has the API's fields, with `title` and `body` read from the type's fields, plus **`readOnly`** (advice, as [Working copy](/reference/swift-sdk/working-copy#declare-pin-catch-up) says) and `unreadableProperties`, which says why `properties` is empty where the copy can't read a row.

`ListFilters` and `SearchFilters` share `types`, `states`, `allStates`, `tier`, `tags`, `occurredAfter`, `occurredBefore`, `filter` and `beneath`. A list adds `source`, `updatedAfter`, `updatedBefore`, `limit` and `offset`.

| Filter | Rule |
| --- | --- |
| `types` | **Up to ten,** each with its subtree, all held. |
| `states` | `nil` is active only. `[.trashed]` lists the bin, newest first. Empty, or beside `allStates`, is refused. |
| `filter` | The server's [listing grammar](/build/list-filter-search). **A `backref` term is refused `invalid`.** |
| `beneath` | An item and what it reaches along `parent-of`, as far as the copy holds. |
| `updatedAfter` | Orders by update time. A `sort` naming another order is refused. |

`Sort(field:direction:)` takes `.createdAt` (the default, descending), `.updatedAt`, `.occurredAt` or `.property(name:)`. `Counted` is `.edge(edgeType:)` for items linking in, `.backref(edgeType:)` for items linked out to, or `.rows(table:)`. An `ItemCount` has `total`, `statusGroups` and `held`. **Only active items count.** Where neither the copy nor the server can answer, it throws `CountError.unavailable`: **show no count, never 0.** `Server.itemCounts(of:_:)` serves an app with no copy.

## Write items

A file is the usual item to write: `addFile` queues the upload and the file item, as [Files](#files) covers. The item shows at once, and an edit names the version the copy holds.

```swift
let added = try await copy.items.addFile(
    pdfURL, Attachment(title: "Tide tables"), tags: ["coast"])
let file = try await copy.items.get(added.item.itemId!)!
try await copy.items.update(
    file.id, Edit(properties: ["title": "Tide tables, 2027"], baseVersion: file.version))
```

Call these on `copy.items`:

| Call | Queues |
| --- | --- |
| `create(_ Draft)` | A create, then **one `addTag` write for each tag.** |
| `update(_:_ Edit)` | An update. **Throws `invalid` unless `baseVersion` is the held version.** |
| `updateAsRead(_:_ Edit)` | An update on an older version, merged against what was read. Takes version `0` for an item this copy created once the server answers. |
| `delete(_:)`, `restore(_:)`, `transition(_:to:from:)` | A move to the bin, a restore, or a change to `.active`, `.archived`, `.trashed` or `.revoked`. **Pass `from`, the state the person saw,** to refuse a stale move. |
| `bin(type:after:limit:)` | One `BinPage` of the server's bin, read online. |
| `purge(_:version:)` | **Destroys a binned item on the server now.** Never queued. Needs `items.purge`. |

`Draft` takes `type`, `properties`, `tags`, `tier`, `state`, `id`, `source`, `sourceId`, `occurredAt`, the capture coordinates and `edges`. `Edit` takes `properties`, `replaceProperties`, `clearProperties`, `baseVersion`, `sourceId`, `type`, `tier`, `occurredAt`, `clearOccurredAt` and `exact`. **Set `exact` where a merge would act on what the person never saw,** such as a move to the feed: if the item has moved past `baseVersion`, the server merges nothing, the write's verdict is refused with the reason `version_conflict` and isn't sent again, and the copy shows the server's item. An exact edit on a version older than the copy holds throws `versionConflict`, with `server` `nil`, and queues nothing, through `updateAsRead` too, unless it reads `0` behind this copy's unanswered create. **A `null` in `properties` clears nothing:** name the property in `clearProperties`. **The copy checks properties against the type** and throws `validation` with `invalid_properties`. `purge` throws `versionConflict` if the item changed since, `invalid` for an item with a write waiting, and `network` offline. A `transition` whose `from` isn't the held state throws `validation` with `state_conflict`, `details.expected` and `details.actual`, and queues nothing; one the server moved first comes back as a refused verdict.

## Edges

| Call | Does |
| --- | --- |
| `edges.from(_:)`, `edges.to(_:)`, `edges.ofType(_:)`, `edges.get(_:)` | Held edges at one end of an item, of one type, or by ID. |
| `edges.create(from:to:type:properties:id:)` | Queues an edge. |
| `edges.update(_:_ EdgeEdit)` | Changes properties or moves one end with `.from(_ id)` or `.to(_ id)`. Returns `nil` for an edit that changes nothing. |
| `edges.check(from:to:type:properties:id:)`, `edges.check(_:moving:)` | Throw what the write would now, and queue nothing. |
| `edges.delete(_:)` | Queues a delete. |

**Every edge read and write throws `hydrationIncomplete` until the copy is whole.** A move of the from end expires the copy once the server accepts it: the drain then throws `copyExpired` with `reach_changed`. A write refuses **in the server's order, with its code,** judged from what the copy holds: `edge_cycle`, `item_not_found` for an end in the bin, `edge_constraint_violation` for a type the edge type doesn't admit, and with `details.constraint` of `"duplicate"` or `"cardinality"`. **Returning isn't the server's verdict:** what the copy doesn't hold, such as a cycle outside its slice, reaches the server.

## Tags, extensions and tables

| Call | Queues |
| --- | --- |
| `tags.add(_:to:)`, `tags.remove(_:from:)` | One tag. An item with **more than 100 tags** throws `validation_error`. |
| `metadata.replaceTags(of:with:)` | Every tag in one write. |
| `extensions.write(_ namespace:_ body:on:readRevision:)`, `extensions.delete(_ namespace:from:readRevision:)` | An extension's whole body, or its removal. Given a read's `revision`, a write over a later change is blocked `conflict_unresolved`, keeping your value. |

A [table](/build/tables) row is never an item. The copy holds a table **whole or not at all,** and reads others from the server.

| Call | Does |
| --- | --- |
| `tables.hold(_ table:ofType:)`, `tables.letGo(_:ofType:)` | Hold that table of every held item of a type, or drop the choice. Queued writes stay. |
| `tables.held()`, `tables.fill()` | The choices and each table's `state` (`.owed`, `.filling`, `.whole` or `.online`), and one fill pass. |
| `tables.rows(of:in:_ RowsQuery)`, `tables.row(_:of:in:)`, `tables.totals(of:in:filter:)` | A `TableRowPage`, one `TableRow`, and `TableTotals`. |
| `tables.write(_ [RowOperation]:to:of:)`, `tables.undo(batch:in:of:)` | One batch (`.put`, `.patch` or `.delete`), and its undo. **No row changes until the server's event arrives.** |

**A `TableAnswer` sets `held` when the copy answered.** Otherwise the server did, after checking it is the instance the copy was built from, or the read throws `copyExpired`. **The server takes all of a batch or none of it,** and a drain gives each batch its own verdict. `RowsQuery` takes `limit` (1 to 1,000), `cursor`, `filter`, `sort` and `direction`.

## Files

A file is **a blob,** its bytes by hash, and **a file item** naming it, queued as separate writes with their own verdicts. [Files](/build/files) explains them.

| Call | Queues |
| --- | --- |
| `items.addFile(_ file:_ Attachment, tags:)` | The upload, a file item, then each tag. |
| `items.attach(to:file:_ Attachment)` | The upload, a file item and an `attached-to` edge to the item. |
| `items.embed(file:in:_ Attachment)` | What `attach` does, and an edit adding `![[title]]` to the body's end. |
| `blobs.put(file:mimeType:)` | The upload alone. |

`Attachment(mimeType:title:type:tier:)` sets the file item; an unset field takes the file's. **An embed reads back as a `references` edge.** `embed` bases its edit on the held body, so a body changed elsewhere meets the type's merge policy, and it throws `EmbedFailure` where the file attached but the body step failed. `items.embedText(of:in:)` gives the embed text.

```swift
let text = try await copy.blobs.withFile(hash) { url in
    try String(contentsOf: url, encoding: .utf8)
}
```

`blobs.withFile(_:_:)` gives `body` the bytes' local URL, **fetching them when the cache lacks them.** Copy the file out to keep it past `body`. A reader or a copy with no server throws `bytesAbsent`. `blobs.isHeld(_:)` asks with no request.

### The file cache

**Files attached to held items stay outside the budget,** so they are there offline once fetched.

| Call | Does |
| --- | --- |
| `blobs.cache()` | The `FileCache`: `setting`, `budget`, `held`, and `attachments`, a `KeptAttachments` count with `notHeldByReason`. |
| `blobs.setBudget(_ FileBudget)`, `blobs.trim()` | Set the budget and trim, or trim now. Return the bytes taken. |
| `blobs.removeFetchedFiles()` | Removes every file the device can fetch again, keeping attachments, queued uploads and files being read. |
| `blobs.fetchKept()` | Fetches every attachment not held, smallest first, resuming partial files. Run it after a hydration and a catch-up. |

`FileBudget` is `.default` (the larger of 2 GiB and a tenth of the volume, leaving a twentieth free), `.bytes(bytes:)` or `.keepAll`. `fetchKept()` stops at a full disk, an unreachable server or a long rate-limit wait, and the files fetched stay. A reader or folder copy throws `readingHandle` from the clearing calls and `fetchKept()`. A `NotHeldReason` is `.notFetched`, `.noRoom`, `.unreachable`, `.rateLimited`, `.absent`, `.failed` or `.notInCopy`. [Keep files in a working copy](/build/keep-files-in-a-working-copy) shows them in use.

## Saved views

A saved view is a `system.view` item, a `SavedView`, never named `View`. **Hydrate with `system.view` in the slice, or pin a view,** to hold it.

| Call | Answers |
| --- | --- |
| `items.views()`, `items.view(_:)` | The held views, or one. |
| `items.list(inView:limit:offset:)`, `items.groups(inView:timeZone:)`, `copy.search(_:inView:limit:)` | The view's items in its sort order, its `ViewGroup`s, and a search narrowed to it. |
| `copy.createView(_ ViewSettings, idempotencyKey:)`, `changeView(_:_ ViewSettingsChange, baseVersion:idempotencyKey:)`, `deleteView(_:idempotencyKey:)` | Write a view **at once, never through the queue.** A delete is for good. |

**A view's reads never answer in part:** they throw `hydrationIncomplete` while the copy fills or is stale, `notFound` for a view not held, and `invalid` where the copy can't answer the whole view, such as a type outside the slice or a revoked view. `ViewSettings` holds `title`, `query` (`types`, `tier`, `states`, `filter`, `beneath`), `sort` and `group` (`by`, `bucket`, `order`, `hidden`). A `filter` takes `status_group`. With no server a write throws `noServer`. **After a `network` failure retry with the same `idempotencyKey`.** A setting changed since `baseVersion` throws `versionConflict`. [Save and read a view](/build/views) shows a view on screen.
