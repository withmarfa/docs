---
title: Sync a folder on a second computer
description: Follow a folder you already sync on one computer from another, so both keep the same files.
---

A folder's settings live on your instance, so **any computer you sign in on can follow the same folder.** Each keeps its own copy of the files in its own directory, and a change on one reaches the others. This page starts from a folder you set up with [Sync a folder](/use/sync-a-folder).

## Sign in on the second computer

[Install the CLI](/quickstart#install-marfa) on the second computer, then sign it in to the same instance:

```bash
marfa login --url https://marfa.example.com
```

The second computer needs its own sign-in, and nothing from the first.

## Find the folder

On the first computer, open `.marfa/folder.yaml` in the folder's directory. The `folder:` line holds its ID:

```yaml title="Home/.marfa/folder.yaml"
folder: 01a1f165-1c9c-71f5-b4b6-e88135e8df1f
```

`marfa folders inventory` also lists the ID of every folder on your instance, with when each last changed, but not its name, so the file is the surer way to pick the right one.

## Add an empty directory

Add a directory on the second computer that follows the folder. **It can be empty, or not exist yet:** the CLI makes it.

<Terminal>

```bash
marfa folders add ~/Home --folder 01a1f165-1c9c-71f5-b4b6-e88135e8df1f
```

```text
/Users/sam/Home follows the folder 01a1f165-1c9c-71f5-b4b6-e88135e8df1f
the first sync will write and send nothing until you confirm it: 3 file(s) to write into the directory, 0 to send to the server
`marfa folders confirm /Users/sam/Home` lets it go; `marfa folders remove /Users/sam/Home` drops the folder and leaves the files
```

</Terminal>

The plan writes a file for every item the folder holds, here the receipt, the photo and the note, and sends nothing, since the directory has no files yet. **Nothing is written until you confirm.** Run in a script with no terminal, the command prints the plan and waits for `confirm` in the same way.

## Confirm and sync

<Terminal>

```bash
marfa folders confirm ~/Home
marfa folders push ~/Home
```

```text
the first sync is confirmed; `folders push` or `folders watch` runs it
0 created, 0 updated, 0 renamed, 0 unchanged, 0 missing, 0 deleted, 0 skipped
the server answered 0 write(s)
3 file(s) written
```

</Terminal>

The directory now holds the same files as the first computer. To confirm as you add, pass `--yes` to `marfa folders add`.

## Keep both in step

**Each computer needs its own watch.** Turn on autostart on the second computer too:

```bash
marfa folders autostart on
```

With a watch on each, an edit on one computer reaches the other as soon as each watch has synced. A deleted file takes a moment longer, because the folder first waits a few seconds in case the file is being moved. A computer that was off catches up when its watch starts again. [Keep folders syncing](/use/keep-folders-syncing) covers the watch, and a computer that nobody logs in to.

## What the computers share

- **The folder's settings.** A change to the query or defaults, made with `marfa folders update` or in `.marfa/folder.yaml` on either computer, applies to both.
- **Where each file sits.** An item has one place in the folder, which every computer follows. Rename or move a file on one computer, and it's renamed or moved on the others. When both computers place the same new item at once, one wins, and the other says `1 placement(s) another machine made first, followed instead`.
- **Not the files' history or queue.** Each computer keeps its own store under `.marfa`, and sends its own edits.

When both computers rewrite a note's body at once, Marfa keeps both edits, as [Sort out a conflicted copy](/use/conflicts) shows.

## Stop following on one computer

`marfa folders remove ~/Home` on one computer stops it following the folder, and leaves its files as plain files. The other computers go on. To retire the folder everywhere, see [Pause or stop syncing a folder](/use/pause-or-stop-a-folder).
