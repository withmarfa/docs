---
title: Sync a folder on a second computer
description: Follow a folder you already sync on one computer from another, so both keep the same files.
---

A folder's settings live on your instance, so **any computer you sign in on can follow the same folder.** Each keeps its own copy of the files in its own directory, and a change on one reaches the others. This page starts from a folder you set up with [Sync a folder](/use/sync-a-folder).

## Sign in on the second computer

[Install the CLI](/quickstart#install-marfa) on the second computer, then sign it in to the same instance:

```bash
marfa login --url https://marfa.example.com
```

The second computer needs its own sign-in, and nothing from the first.

## Find the folder

List the folders on your instance:

<Terminal>

```bash
marfa folders inventory
```

```text
id                                    when
01a1f136-323f-708f-91fd-679a08733fa5  2026-11-19T00:30:23.295Z
```

</Terminal>

If you have several, the folder's ID is also in `.marfa/folder.yaml` on the first computer, on the `folder:` line.

## Add an empty directory

Add a directory on the second computer that follows the folder. **It can be empty, or not exist yet:** the CLI makes it.

<Terminal>

```bash
marfa folders add ~/Notes --folder 01a1f136-323f-708f-91fd-679a08733fa5
```

```text
/Users/sam/Notes follows the folder 01a1f136-323f-708f-91fd-679a08733fa5
the first sync will write and send nothing until you confirm it: 65 file(s) to write into the directory, 0 to send to the server
`marfa folders confirm ~/Notes` lets it go; `marfa folders remove ~/Notes` drops the folder and leaves the files
```

</Terminal>

The plan writes a file for every note the folder holds, and sends nothing, since the directory has no files yet. **Nothing is written until you confirm.** Run in a script with no terminal, the command prints the plan and waits for `confirm` in the same way.

## Confirm and sync

<Terminal>

```bash
marfa folders confirm ~/Notes
marfa folders push ~/Notes
```

```text
the first sync is confirmed; `folders push` or `folders watch` runs it
0 created, 0 updated, 0 renamed, 0 unchanged, 0 missing, 0 deleted, 0 skipped
the server answered 65 write(s)
65 file(s) written
```

</Terminal>

The directory now holds the same notes as the first computer. To confirm as you add, pass `--yes` to `marfa folders add`: the push then starts with a line such as `hydrated 69 item(s) first`, which says it fetched what the folder holds, attached files included, before writing them out.

**The files mean the same on both computers, but may not match byte for byte.** The computer that sent a note keeps its own frontmatter as you wrote it, and a computer that receives it writes the frontmatter in Marfa's order. A `marfa_version` line can trail your instance's for a moment, and an edit made from it still merges.

## Keep both in step

**Each computer needs its own watch.** Turn on autostart on the second computer too:

```bash
marfa folders autostart on
```

With a watch on each, an edit on one computer reaches the other within a second or so, and a deleted file within about 10 seconds. A computer that was off catches up when its watch starts again. [Keep folders syncing](/use/keep-folders-syncing) covers the watch, and a computer that nobody signs in to.

## What the computers share

- **The folder's settings.** A change to the query or defaults, made with `marfa folders update` or in `.marfa/folder.yaml` on either computer, applies to both.
- **Where each file sits.** A note has one place in the folder, which every computer follows. Rename or move a file on one computer, and it's renamed or moved on the others. When both computers place the same new note at once, one wins, and the other says `1 placement(s) another machine made first, followed instead`.
- **Not the files' history or queue.** Each computer keeps its own store under `.marfa`, and sends its own edits.

When both computers change the same part of a note at once, Marfa keeps both edits, as [Sort out a conflicted copy](/use/conflicts) shows.

## Stop following on one computer

`marfa folders remove ~/Notes` on one computer stops it following the folder, and leaves its files as plain files. The other computers go on. To retire the folder everywhere, see [Stop or remove a folder](/use/pause-or-stop-a-folder).
