---
title: Limits
description: The size, rate and time limits an instance holds to, and the setting that changes each one that can change.
job: Anyone checks a limit on size, requests or how long things are kept, and the setting that changes it.
---

A limit with a setting changes with `marfa config set <setting> <value>`. The others are fixed. [Change an instance's settings](/run/settings) lists every setting with its range, and `marfa config settings` shows each value on your instance.

| Limit | Value | Setting |
| --- | --- | --- |
| A note's body, or another type's main text | 1,000,000 characters | Fixed |
| Any other text field | 100,000 characters, unless its type sets its own | Fixed |
| Tags on one item, and one tag | 100 tags, 128 characters | Fixed |
| An ordinary request body | 1 MiB | `max_request_bytes` |
| One bulk write | 16 MiB | `max_bulk_request_bytes` |
| A file | No fixed size. Marfa refuses a file that would leave less than 128 MiB free on its disk | `disk_reserve_bytes` |
| A file an agent fetches from a web address | 50 MiB, 60 seconds | `mcp_fetch_max_bytes`, `mcp_fetch_timeout_seconds` |
| Requests from one app or key | 4,000 in each window of 60 seconds | `rate_limit_requests`, `rate_limit_window_seconds` |
| Requests to the key operations from one credential | 200 in each window | `rate_limit_keys_requests` |
| Items moved to the bin in one command | 20 | Fixed |
| Items in one page of a list | 500 at most | Fixed |
| A search | 500 characters, and at most 16 different words unless the whole query is in double quotes | Fixed |
| A filter | 2,048 characters and 10 conditions, with at most 100 tags in one tag filter and 10 types in one type filter | Fixed |
| An item in the bin | 60 days, then housekeeping may delete it for good | `trash_retention_days` |
| Earlier versions of an item | Every version for 30 days, one a day to 90 days, one a week to a year, up to 500 | `version_recent_days`, `version_daily_snapshot_days`, `version_weekly_snapshot_days`, `version_max_versions` |
| An app's approval, once unused | 365 days | `grant_inactivity_days` |
| The audit log | 90 days, or forever with `0` | `audit_retention_days` |
| An event in the event log, at least | 30 days | `event_log_retention_days` |

A type can set its own field lengths and keep versions on its own terms: its page in the [Catalog](/catalog/types) shows them. When an app or a key goes over its requests, your instance asks it to wait. A synced folder waits and carries on by itself, as [Fix a folder](/use/fix-a-folder#the-server-asked-for-a-wait-before-more-is-sent) shows.
