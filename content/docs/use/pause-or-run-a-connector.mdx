**Marfa stores what you ask of a plugin's connector, and its host follows that.** Marfa starts and stops nothing itself. [The connector kit](/reference/connector-kit#pause-run-now-and-previews) says how a paused connector skips a run, how a run already going finishes, and how the host wakes a sleeping connector for a run now. Each command needs `connectors.manage`.

## Check it

<Terminal>

```bash
marfa plugins status rss
```

```text
rss's connector: running as scheduled; host no host; mapping version 1; 0 rewrites and 0 previews waiting
```

</Terminal>

The line says whether the connector is `paused`, `asked to run` at a time, or `running as scheduled`. Then it names the host (`no host` until you [assign one](/use/run-a-plugin-connector)), the version of [its mapping](/use/map-a-connector), and how many [rewrites](/use/rewrite-connector-records) and previews are still waiting.

## Pause and resume it

```bash
marfa plugins pause rss
marfa plugins resume rss
```

Pause prints the same line with `paused` in place of `running as scheduled`. **Pausing removes nothing:** the key, the settings, the mapping and the items stay. Resume prints `running as scheduled` again. Pausing also drops a run you had asked for, so resuming does not start one.

## Run it now

```bash
marfa plugins run rss
```

The connector runs on its next look, instead of waiting for its schedule. Asking twice before it looks still gives one run. When the connector reports that run, the request clears and the status line says `running as scheduled` again.

A paused connector is refused:

```text
marfa: the server refused (409 connector_paused): The connector of plugin rss is paused. Resume it, then ask it to run. {"plugin":"rss"}
```

Resume it, then ask again.

The [audit log](/use/audit-log) records each choice as `connector.pause`, `connector.resume` and `connector.run_request`. Removing the plugin removes them. The rules are in the plugins chapter of the contract, under [Pausing and running a connector](https://github.com/withmarfa/marfa/blob/main/conformance/spec/plugins.md#pausing-and-running-a-connector).
