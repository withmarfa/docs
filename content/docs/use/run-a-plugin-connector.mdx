A plugin can bring a **connector** with its types. Marfa records it when you install the plugin, and a **connector host** runs it: a program on a machine you link to your instance once. The host gets each connector's key from Marfa, so you never copy a key to it. Every step needs `connectors.manage`, which the CLI signed in as you holds.

The connectors in the [Catalog](/catalog/connectors) don't come as plugins yet: run one as [Bring in records from another service](/use/connect-a-service) shows.

## Add a host

Name the host after its machine. The CLI prints a **one-time link**, which works once and only for 15 minutes:

<Terminal>

```bash
marfa hosts add "Studio Mac"
```

```text
host Studio Mac (01a1fa31-0d2e-7c4a-9b51-3f2c8e6d1a07); give this link to the host program once, before 2026-11-21T10:15:00.000Z:
https://marfa.example.com/connect#marfa_l1_4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f
```

</Terminal>

Give the link to the host program on that machine ([Build a connector host](/build/connector-host) says what one does). **Redeeming it gives the host a key of its own,** which can only ask which connectors it runs and get their keys. Its code sits after the `#`, so no proxy's log holds it. A link that ended needs a fresh one: `marfa hosts link "Studio Mac"`.

## Assign a connector

Name the host when you install the plugin, or assign it afterward:

```bash
marfa plugins install ./rss --host "Studio Mac"
marfa plugins assign rss --host "Studio Mac"
```

An install without `--host` says the connector `runs on no host yet`, and names the command. The host then gets the connector's key: it holds the connector's source and write on its types, and its records land in the feed unless [the mapping](/use/map-a-connector) says otherwise. Set what the connector needs first: [Give a connector its settings](/use/connector-settings).

`marfa hosts list` shows each host, whether it's linked, when it was last seen, and its connectors, each with `key_minted`.

## Move a connector or a host

- **Another host:** `marfa plugins assign rss --host <other>`. Marfa revokes the key the first host minted, and the second mints its own. `--none` leaves it on no host, and its key is revoked.
- **A new machine:** run `marfa hosts link "Studio Mac"` and give the new machine the link. Redeeming it revokes the old machine's host key, and each connector key the new machine mints revokes the one before.

**A connector's state stays on the instance,** under its source, so it resumes where it stopped on any host.

## Remove a host or a plugin

<Terminal>

```bash
marfa hosts remove "Studio Mac"
```

```text
removed host Studio Mac; revoked 2 keys; these connectors now run on no host: rss
```

</Terminal>

`marfa plugins remove rss` stops its connector too: it revokes the connector's key and removes its registrations, settings and mapping. **Its types, items, state and agreements stay,** so installing it again picks up where it stopped. [Install a plugin](/use/install-a-plugin#list-and-remove-plugins) says what else stays.

The rules behind this page are in the [plugins](https://github.com/withmarfa/marfa/blob/main/conformance/spec/plugins.md#connector-hosts) chapter of the contract.
