A plugin can bring a **connector** with its types. Marfa records the connector when you install the plugin. A **connector host** is a program on a machine you link once, and it runs the connector. The host mints each connector's key, so you never copy a key onto the machine. [The connector kit](/reference/connector-kit#the-key) says what that key can do. Every step needs `connectors.manage`, which the CLI signed in as you holds.

Marfa does not publish a connector host yet. Installing WithMarfa's connectors by name, and the steps to install a host, are coming. This page is the server half: you link a machine and assign a connector. [Build a connector host](/build/connector-host) says what a host does. The latest release installs **Tickets** by name. A connector's source folder comes from a clone of [withmarfa/plugins](https://github.com/withmarfa/plugins).

## Add a host

Name the host after its machine. The CLI prints a **one-time link**, which works once and only for 15 minutes:

<Terminal>

```bash
marfa hosts add "Studio Mac"
```

```text
host Studio Mac (01a1fa31-0d2e-7c4a-9b51-3f2c8e6d1a07); give this link to the host program once, before 2026-11-21T10:15:00.000Z:
https://marfa.example.com/connect#marfa_l1_4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f4f
```

</Terminal>

Give that link to the host program on the machine. **Redeeming it gives the host a key of its own,** which can only ask which connectors it runs and get their keys. The link's code sits after the `#`, so a proxy's log doesn't hold it. A link that has ended needs a fresh one: `marfa hosts link "Studio Mac"`.

## Assign a connector

Install the plugin, then set what it needs ([Give a connector its settings](/use/connector-settings)). A setting for a plugin that is not installed is refused `404 plugin_not_found`. The folder below is `connectors/rss/plugin` in a clone of [withmarfa/plugins](https://github.com/withmarfa/plugins):

```bash
marfa plugins install ./connectors/rss/plugin
marfa plugins settings rss --set rss_pictures=save
marfa plugins secret rss rss_feeds
marfa plugins assign rss --host "Studio Mac"
```

An install with no `--host` says the connector runs on no host yet and names `marfa plugins assign`. When the instance has exactly one host, that line names the host and assigns nothing. This page uses `marfa plugins assign` once the settings are stored. The host then mints the connector's key. Where each kind of record lands is [the mapping](/use/map-a-connector).

`marfa hosts list` shows each host, whether it is linked, when it was last seen, and its connectors, each with `key_minted`.

## Move a connector or a host

- **Another host.** `marfa plugins assign rss --host <other>` revokes the key the first host minted, and the second mints its own. `--none` leaves the connector on no host, and its key is revoked.
- **A new machine.** `marfa hosts link "Studio Mac"` prints a fresh link. Redeeming it revokes the old machine's host key. Each connector key the new machine mints revokes the one before it.

**A connector's state stays on the instance,** under its source, so it resumes where it stopped.

## Remove a host or a plugin

<Terminal>

```bash
marfa hosts remove "Studio Mac"
```

```text
removed host Studio Mac; revoked 2 keys; these connectors now run on no host: rss
```

</Terminal>

`marfa plugins remove rss` stops its connector too. [Install a plugin](/use/install-a-plugin#list-and-remove-plugins) says what stays: the types and their items, and the source's state and agreements.

The rules are in the [plugins](https://github.com/withmarfa/marfa/blob/main/conformance/spec/plugins.md#connector-hosts) chapter of the contract.
