Saving [a connector's mapping](/use/map-a-connector) changes no item. The records the connector already brought stay where they landed: on the kind's own type, or on a type you mapped the kind onto before. **A rewrite asks the connector to move them onto each kind's target,** filling their fields as the mapping says. Map a kind back to its own type, or onto another type, and a rewrite brings its records with it. Each command needs `connectors.manage`.

## Count what a rewrite would move

<Terminal>

```bash
marfa plugins mapping rewrite tracker --dry-run
```

```text
a rewrite of tracker would move issue: 214 onto core.task
```

</Terminal>

The count is the connector's records outside the bin on each type the rewrite moves from. Records already on the target aren't counted, and stay where they are. A kind that is off counts 0, because a rewrite moves none of its records.

## Ask for the rewrite

```bash
marfa plugins mapping rewrite tracker --kind issue
```

Without `--kind`, it asks for every kind that is on. Marfa stores a numbered request, and the connector carries it out on its next run and then clears it. Until then, `marfa plugins mapping show tracker` lists the request under `rewrites`, with the types it moves each kind's records from under `from`. Asking again before the connector runs stores another request.

## What the connector may reach meanwhile

**While the request waits, the connector can read its own records on a type you mapped the kind onto before, and move them onto the kind's target.** It can't create or edit records there, and it never reaches your own records or another source's. That reach ends once the connector clears every request naming the kind.

An archive carries the requests still waiting and the types each kind was mapped onto before, so a rewrite after a restore moves the same records ([Move your data with an archive](/run/export-and-restore)).

The rules behind this page are in the [plugins](https://github.com/withmarfa/marfa/blob/main/conformance/spec/plugins.md#rewriting-existing-items) chapter of the contract.
