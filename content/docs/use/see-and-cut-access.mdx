This page will show how to see what can reach an instance and what it did, and how to narrow or revoke an app, a key or an agent from any machine.

## See what it did, and stop it

**Every write is in the [audit log](/use/audit-log)** with the credential that made it, and a write through a tool also carries `"via": "mcp"`. `marfa items list --source nightly-digest` lists what a keyed agent created.

You can **stop an agent at once**. Revoke its key with `marfa keys revoke <key id>`, or disconnect a signed-in agent on the **Connected apps** page, as [Authenticate](/build/authenticate#revoke-access) describes. Its next request is refused.
