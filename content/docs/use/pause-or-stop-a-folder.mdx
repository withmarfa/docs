This page will show how to pause a folder by stopping its watch, how one computer stops following it, and how to retire the folder on the instance.

## Stop following a folder

To stop following a folder on one computer, run `marfa folders remove Notes`, which is refused while writes wait, apart from a first sync awaiting confirmation. The folder's state goes, and **the files stay, as plain files**. Added again, it [takes each file back](/folder-rules#a-folder-added-again-over-its-files) as the item it was.
