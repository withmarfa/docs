---
title: Pause or stop syncing a folder
description: Stop a folder syncing for a while, stop following it on one computer, or retire it on your instance.
---

There are three ways to stop a folder, from the lightest to the last.

| To | Run | What stays |
| --- | --- | --- |
| Stop syncing for a while | `marfa folders autostart off` | Everything. Turn autostart on again to carry on. |
| Stop following on one computer | `marfa folders remove ~/Notes` | The files, as plain files. Other computers go on. |
| Retire the folder everywhere | `marfa folders revoke <id>` | The files on each computer, and every note on your instance. |

None of them deletes a note.

## Stop syncing for a while

There's no pause command: **a folder syncs only while a watch runs.** Stop the watch, and the folder stays as it is until you start one again.

- **If autostart runs the watch,** turn it off. This stops every folder on the computer:

  ```bash
  marfa folders autostart off
  ```

- **If you started the watch yourself,** press Ctrl-C in its terminal.

You can go on editing the files meanwhile. **Nothing is lost:** when you start the watch again, with `marfa folders autostart on` or `marfa folders watch`, it sends what you changed and takes in what changed elsewhere, merging the two as [Sort out a conflicted copy](/use/conflicts) shows.

To stop only one folder and keep the others syncing, remove it from the computer, as the next section shows, and add it again later.

## Stop following on one computer

<Terminal>

```bash
marfa folders remove ~/Notes
```

```text
/Users/sam/Notes is no longer a folder; its files stay
```

</Terminal>

The folder's own store under `.marfa` goes, and **the files stay as plain files** that no longer sync. Your notes stay on your instance, and other computers that follow the folder go on.

`remove` is refused while edits wait to be sent, so nothing you changed is lost: run `marfa folders push ~/Notes` first. A first sync that waits for you to confirm it is canceled instead.

**To follow the folder again,** run `marfa folders add` with its ID. It takes each file back as the note it was, by its `marfa_id`, and makes no duplicates.

## Retire the folder everywhere

To be done with a folder on every computer, such as one you made to try something, revoke it on your instance. First find its ID with `marfa folders inventory`, or on the `folder:` line of `.marfa/folder.yaml`:

```bash
marfa folders revoke 01a1f136-323f-708f-91fd-679a08733fa5
```

The folder's settings are retired for good: `folders inventory` no longer lists it, and it can't be changed or brought back. **Its notes stay on your instance,** untouched. A computer that still follows it can't sync, and says so:

```text
marfa: the folder 01a1f136-323f-708f-91fd-679a08733fa5 is revoked, and a revoked folder has no settings to follow
```

Run `marfa folders remove` on each such computer to keep its files as plain files.

A folder isn't an item you move to the bin: `marfa items trash` refuses it with `403 type_not_permitted`, because Marfa manages the folder's settings itself. Use `revoke`.
