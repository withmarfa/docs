Your notes, tasks, bookmarks and files live in one instance, as typed items. Your apps, scripts and AI agents read and write them through one API, each reaching only what you allow, and apps built on the Swift SDK keep working offline. These docs cover running an instance and building on it.

<Callout type="warn" title="Marfa is early">Expect breaking changes until version 1.0.</Callout>

## Build on Marfa

Apps and agents share the same data, through the Swift and TypeScript SDKs, the CLI or plain HTTP.

- [Build an app with Swift](/guides/swift-app): an iPhone and Mac app that works offline.
- [Use Marfa with AI agents](/guides/ai-agents): give an agent a key that reaches only what it needs.
- [Build a connector](/guides/connector): bring records from another service into Marfa.
- [Define a type](/guides/define-a-type): register a type of your own, with its fields.

## Run Marfa

An instance is one SQLite database file and a folder of files, on your Mac, a home server or Railway.

- [Deploy](/guides/deploy): choose where it runs and how your devices reach it.
- [Back up and restore](/guides/back-up-and-restore): keep a copy of the data and secrets, and bring them back.
- [Troubleshooting](/guides/troubleshooting): the cause and the fix for the problems people meet first.
