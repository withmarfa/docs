---
title: Docs MCP server
description: Connect an AI agent to these docs over MCP, so it searches and reads the current pages instead of working from memory.
---

The docs MCP server lets an agent search and read these docs while it works. It runs at `https://docs.marfa.so/mcp`, over the Streamable HTTP transport, and needs no credential.

<Callout title="It reads the docs, not your data">This server searches docs.marfa.so. It can't reach your instance. To give an agent your data, give it a key and the CLI, as [Use Marfa with AI agents](/guides/ai-agents) shows.</Callout>

## Connect it

Add the server to your agent as a remote HTTP server:

<Tabs items={["Claude Code", "Codex"]}>
<Tab value="Claude Code">

Add it to a project's `.mcp.json`, so everyone who works in the project has it:

```json title=".mcp.json"
{
  "mcpServers": {
    "marfa-docs": {
      "type": "http",
      "url": "https://docs.marfa.so/mcp"
    }
  }
}
```

Or add it from a terminal. `--scope project` writes it to `.mcp.json`; leave it out to add it for yourself only:

```bash
claude mcp add --transport http marfa-docs --scope project https://docs.marfa.so/mcp
```

</Tab>
<Tab value="Codex">

Add it to `~/.codex/config.toml`, or to a trusted project's `.codex/config.toml`:

```toml title="config.toml"
[mcp_servers.marfa-docs]
url = "https://docs.marfa.so/mcp"
```

Or add it from a terminal:

```bash
codex mcp add marfa-docs --url https://docs.marfa.so/mcp
```

</Tab>
</Tabs>

## Its tools

The server gives the agent three read-only tools:

| Tool | Input | Answer |
| --- | --- | --- |
| `docs_search` | `query`, and an optional `limit` from 1 to 50 | The pages that match, best first, each with its title, path and snippets |
| `docs_fetch` | `path`, such as `/files` | The page as Markdown |
| `docs_list_topics` | None | Every page, with its title, path and description |

When `docs_fetch` finds no page at the path, it answers with an error result whose `error` is `not_found`.

An agent with no MCP can read the same pages through [Docs as Markdown](/docs-as-markdown).
