Marfa uses each word below in one sense only, in its code, its API and these docs. Each links to the page that explains it.

## Your data

| Word | What it means |
| --- | --- |
| [**item**](/items-and-types) | One record, such as a note or a task. |
| [**type**](/items-and-types) | What an item is, such as `core.note`, and the properties it must hold. |
| [**namespace**](/items-and-types#what-a-type-does) | The part of a name that says whose it is: a type identifier's first segment, such as `core`, or an extension's name, such as `com.example.reader`. |
| [**property**](/properties-metadata-and-edges#properties) | A named value in an item, declared by its type. |
| [**tag**](/properties-metadata-and-edges#tags) | A free-form label on an item, such as `favorite`. |
| [**extension**](/properties-metadata-and-edges#extensions) | An app's own data about an item, under a namespace. |
| [**edge**](/properties-metadata-and-edges#edges) | A typed link from one item to another. |
| [**edge type**](/properties-metadata-and-edges#edges) | What an edge is, such as `about`, and the rules its edges follow. |
| [**reverse name**](/properties-metadata-and-edges#edges) | An edge's name read from its target: `child-of` for `parent-of`. |
| [**file**](/files) | An item that names its bytes. |
| [**blob**](/files) | A file's bytes, stored once under a hash of their content. |
| [**state**](/items-and-types#an-items-life) | `active`, `archived` or `trashed`; `active` or `revoked` for a `system` item. |
| [**tier**](/items-and-types#library-and-feed) | The **library**, what a person kept, or the **feed**, what arrived from elsewhere. |
| [**version**](/versions) | A count of an item's changes, which a write names. |
| [**conflicted copy**](/versions) | A new item that keeps the losing side of a collision. |

## Changes

| Word | What it means |
| --- | --- |
| [**event**](/events) | A record of one change in the instance's log. Not a `core.event` item. |
| [**event type**](/catalog/events) | What an event says changed, such as `item.updated`. |
| [**cursor**](/events#the-event-log) | The ID of the last event an app handled. |
| [**webhook**](/events#webhooks) | A URL Marfa posts events to. |

## Access

| Word | What it means |
| --- | --- |
| [**owner**](/access#who-can-act) | The one person an instance belongs to, who decides what each key and app reaches. |
| [**credential**](/access) | A key or an access token. |
| [**key**](/guides/manage-keys) | A credential for a script, an agent or a connector, beginning `marfa_k1_`. |
| [**app**](/guides/authenticate) | A program that signs in with OAuth. |
| [**access token**](/guides/authenticate) | An app's credential, beginning `marfa_at_`. |
| [**scope**](/guides/authenticate#connect-an-app-with-oauth) | One thing an app asks for, such as `core.note:read`. |
| [**map**](/access#what-a-credential-reaches) | The part of a credential that names the data it reaches, at `read` or `write`. |
| [**permission**](/access#permissions) | The right to a group of operations. It opens no items. |
| [**lever**](/guides/settings#what-the-enforcement-levers-do) | A setting that holds chosen types to a stricter rule. |
| [**source**](/items-and-types#where-an-item-came-from) | The program that created an item, set by the key that created it. |
| [**`source_id`**](/items-and-types#where-an-item-came-from) | An item's own ID at its source. |
| [**setup code**](/quickstart#claim-the-instance) | A one-time code for claiming a new instance. |

## The instance

| Word | What it means |
| --- | --- |
| [**instance**](/how-marfa-works#the-instance) | One running Marfa server and its data, owned by one person. |
| [**operation**](/api-reference) | One thing the API does, such as creating an item. |
| [**housekeeping**](/guides/housekeeping) | Work an instance does on itself on a schedule. |
| [**contract**](https://github.com/withmarfa/marfa/tree/main/conformance/spec) | The written rules Marfa follows, each checked by tests. |

## Devices and folders

| Word | What it means |
| --- | --- |
| [**device**](/devices) | A client that keeps a working copy, such as an iPhone app. |
| [**working copy**](/devices#the-working-copy) | The data a device keeps on its own disk. |
| [**slice**](/devices#the-working-copy) | The types, tier and edge types a working copy holds. |
| [**queue**](/devices#a-write-made-offline) | A device's writes waiting to be sent. |
| [**drain**](/devices#a-write-made-offline) | One pass that sends the queue. |
| [**verdict**](/devices#verdicts) | What became of a queued write, such as `accepted` or `dead`. |
| [**folder**](/guides/sync-a-folder) | A directory of files kept in step with a set of items. |

## Connectors

| Word | What it means |
| --- | --- |
| [**connector**](/connectors) | A program that brings in records from another service. |
| [**hold**](/guides/connector-holds-and-retries) | What lets one copy of a connector write at a time. |
| [**agreement**](/connectors) | What a connector and its service last agreed about one item. |
| [**webhook endpoint**](/guides/connector-webhooks) | An address on an instance that a service posts to, for a connector to read. |

## The CLI

| Word | What it means |
| --- | --- |
| [**CLI**](/cli) | The `marfa` program, Marfa's command-line tool. |
| [**command**](/cli#find-a-command) | One thing the CLI does, such as `marfa items list`. |

The full vocabulary, with the words Marfa avoids, is [marfa's GLOSSARY.md](https://github.com/withmarfa/marfa/blob/main/GLOSSARY.md).
