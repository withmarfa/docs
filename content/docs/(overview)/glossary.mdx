Marfa uses each word below in one sense only, in its code, its API and these docs. Each links to the page that explains it.

## Your data

| Word | What it means |
| --- | --- |
| [**item**](/items-and-types) | One record, such as a note or a task. |
| [**type**](/items-and-types) | What an item is, such as `core.note`, and the properties it must hold. |
| [**namespace**](/items-and-types#what-a-type-does) | The part of a name that says whose it is: a type identifier's first segment, such as `core`, or an extension's name, such as `com.example.reader`. |
| [**property**](/properties-and-metadata#properties) | A named value in an item, declared by its type. |
| [**tag**](/properties-and-metadata#tags) | A free-form label on an item, such as `favorite`. |
| [**extension**](/properties-and-metadata#extensions) | A JSON object an app keeps on an item, under a namespace of its own. |
| [**edge**](/edges) | A directed relationship from one item to another, named by its edge type. |
| [**edge type**](/edges#edge-types) | What an edge is, such as `about`, and the rules its edges follow. |
| [**reverse name**](/catalog/edges) | An edge's name read from its target: `child-of` for `parent-of`. |
| [**label**](/catalog/edges) | The heading a type, a field or an edge type shows for itself. An edge type's label heads the source's end of an edge, such as `Children` for `parent-of`. |
| [**reverse label**](/catalog/edges) | The heading an edge type shows for the target's end, such as `Parent`. Where an edge type names none, its label names both ends. |
| [**collection**](/catalog/edges) | A flat container of items. An item joins one through an `in-collection` edge to an item whose type has the `container` role, such as a [`core.collection`](/catalog/collection) or an album. An item can be in many, a container can't itself be a member, and deleting the container leaves its members. |
| [**view**](/build/save-a-view) | A saved query with one sort and one grouping, kept on the instance as a `system.view` and shared by every app. How an app draws the items is the app's own. |
| [**file**](/files) | An item whose type inherits from `core.file`, which refers to the blob that holds its bytes. |
| [**blob**](/files) | A file's bytes, stored once under a hash of their content. |
| [**attachment**](/build/handle-files) | An item, usually a file, joined to another by an `attached-to` edge from itself, such as a photo on a note. It goes to the bin with the last item it's attached to. A device keeps an attached file's bytes, and a folder writes it beside the document or where an embed says. |
| [**embed**](/build/handle-files) | A file an item's body shows, written `![](path)` or `![[file]]`, making a `references` edge to it. It attaches the file only in a folder whose query doesn't hold it. |
| [**state**](/items-and-types#an-items-life) | `active`, `archived` or `trashed`; `active` or `revoked` for a `system` item. |
| [**tier**](/items-and-types#library-and-feed) | The **library**, what a person kept, or the **feed**, what arrived from elsewhere. |
| [**version**](/versions) | A number on an item or an edge that rises with each change. An update names the version it read. |
| [**conflicted copy**](/versions) | A new item that keeps the losing side of a collision. |

## Changes

| Word | What it means |
| --- | --- |
| [**event**](/events) | A record of one change in the instance's log. Not a `core.event` item. |
| [**event type**](/catalog/events) | What an event says changed, such as `item.updated`. |
| [**cursor**](/events#the-event-log) | The ID of the last event an app handled. |
| [**webhook**](/events#webhooks) | A URL Marfa posts events to. |

## Access

| Word | What it means |
| --- | --- |
| [**owner**](/access#who-can-act) | The one person an instance belongs to, who decides what each key and app reaches. |
| [**credential**](/access) | A key or an access token. |
| [**key**](/run/manage-keys) | A credential beginning `marfa_k1_`, for a script, an agent or a connector. Its permissions and maps say what it reaches. |
| [**app**](/build/authenticate) | A program the owner signs in to the instance with OAuth, acting within what the owner approved. Granted `keys.mint`, it can make keys, which name it in `oauth_client_id`. |
| [**access token**](/build/authenticate) | An app's credential, beginning `marfa_at_`. |
| [**scope**](/build/authenticate#connect-an-app-with-oauth) | One thing an app asks for, such as `core.note:read`. |
| [**map**](/access#what-a-credential-reaches) | The part of a credential that names the data it reaches, at `read` or `write`. |
| [**permission**](/access#permissions) | The right to a group of operations. It opens no items. |
| [**lever**](/run/settings#what-the-enforcement-levers-do) | A setting that holds chosen types to a stricter rule. |
| [**source**](/items-and-types#where-an-item-came-from) | The code an item carries to say what wrote it: a key's own source, one it claims, or an app's, starting `oauth:`. |
| [**`source_id`**](/items-and-types#where-an-item-came-from) | An item's own ID at its source. |
| [**setup code**](/quickstart#claim-the-instance) | A one-time code for claiming a new instance. |

## The instance

| Word | What it means |
| --- | --- |
| [**instance**](/how-marfa-works#the-instance) | One Marfa: the deployment that holds one owner's data, with an `instance_id` of its own. The **server** is the software that answers its requests. |
| [**operation**](/api-reference) | One thing the API does, such as creating an item. |
| [**MCP**](/marfa-mcp-server) | The protocol AI agents use to call tools. An instance serves its tools at `/mcp`, `/mcp/schema` and `/mcp/admin`, and each tool call is a call to the API made with the agent's credential. |
| [**housekeeping**](/run/housekeeping) | Jobs the server runs on itself on a schedule, such as purging the bin. |
| [**contract**](https://github.com/withmarfa/marfa/tree/main/conformance/spec) | The written rules Marfa follows, each checked by tests. |

## Devices and folders

| Word | What it means |
| --- | --- |
| [**device**](/devices) | A program that keeps a working copy and a queue of writes, such as an iPhone app built on the Swift SDK, or the CLI. It is not the machine the program runs on. |
| [**working copy**](/devices#the-working-copy) | A device's own copy of its slice, on its disk. It's a copy, not a peer: the server holds the truth. |
| [**slice**](/devices#the-working-copy) | The types, tier and edge types a working copy holds. |
| [**queue**](/devices#a-write-made-offline) | A device's writes waiting to be sent. |
| [**drain**](/devices#a-write-made-offline) | One pass that sends the queue. |
| [**verdict**](/devices#verdicts) | What became of a queued write, such as `accepted` or `dead`. |
| [**folder**](/run/sync-a-folder) | A device whose working copy is a directory on a computer: each item a query matches is a file in it, and a file added there becomes an item. Its settings live on the instance as a `system.folder`, shared by every computer that follows it, and each computer keeps its own working copy and queue. Not a view, which lists items and holds none as files. |

## Connectors

| Word | What it means |
| --- | --- |
| [**connector**](/connectors) | A program outside the server that reads or writes on a person's behalf, such as one that keeps another service's records in step. The server never runs one. |
| [**hold**](/build/connector-holds-and-retries) | What lets one copy of a connector write at a time. |
| [**agreement**](/connectors) | What a connector and its service last agreed about one item. |
| [**inbound endpoint**](/build/connector-webhooks) | An address on an instance that a service posts to, for a connector to read. |

## The CLI

| Word | What it means |
| --- | --- |
| [**CLI**](/cli) | The `marfa` program, Marfa's command-line tool. |
| [**command**](/cli#find-a-command) | One thing the CLI does, such as `marfa items list`. |

The full vocabulary, with the words Marfa avoids, is [marfa's GLOSSARY.md](https://github.com/withmarfa/marfa/blob/main/GLOSSARY.md).
