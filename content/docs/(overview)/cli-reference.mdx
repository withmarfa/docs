This is the help of every command the CLI has, generated from its own help text on the `main` branch of Marfa. A release can lag behind `main`, so this page can list a command the latest release doesn't have; `marfa <command> --help` prints the help of the build you have. To install the CLI and connect it to a server, see [CLI](/cli).
