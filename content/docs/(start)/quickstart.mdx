---
title: Quickstart
description: Install Marfa on your Mac or Linux computer, connect an agent to it, and save and find your first file.
job: A newcomer installs Marfa, connects an agent, and saves and finds a first file.
---

- **You'll build** a Marfa instance on your own computer, with you as its owner.
- **You need** a Mac with Apple silicon or a Linux computer, a terminal, and Claude Code or Codex for the agent steps.
- **You'll have** a first file saved in Marfa, and an agent that finds it and saves more.

**On Railway instead?** [Deploy and claim it there](/run/run-on-a-server#on-railway), install the CLI below, and use your Railway address for `http://localhost:8600`.

<Steps paged>
<Step>

### Install Marfa

One script installs the CLI, `marfa`, and the server, `marfa-server`, into `~/.local/bin`:

<Terminal>

```bash
curl -fsSL https://raw.githubusercontent.com/withmarfa/marfa/main/scripts/install.sh | sh
```

```text
Installed marfa 0.0.81 and marfa-server 0.0.81 to /Users/sam/.local/bin.
```

</Terminal>

If the script says that folder **is not on your `PATH`**, add the `export PATH=` line it prints to your shell's startup file, then open a new terminal.

</Step>
<Step>

### Start the server

Start a server that only this computer reaches, with no Docker or database to set up. [Install on a Mac or Linux machine](/run/install) covers the other ways to reach it.

<Terminal>

```bash
marfa server install --access local
```

```text
Marfa 0.0.81 is running.
  Address   http://localhost:8600
  http://localhost:8600/setup#handoff=6f1c…
```

</Terminal>

<Callout type="warn" title="Two things to do before you rely on Marfa">
**Copy `marfa.env` somewhere safe,** such as your password manager. It's in `~/marfa-server`, and it holds two secrets your data needs that aren't kept anywhere else. **Set up backups,** because the server keeps none until you give it somewhere to put them: see [Back up and restore](/run/back-up-and-restore).
</Callout>

</Step>
<Step>

### Create your account

Open the setup link the command printed. It works once, for five minutes. On **Create your account**, enter your name, email address and a password, and select **Create account**.

You're now the owner, and **nobody else can claim the instance.**

</Step>
<Step>

### Sign in from the CLI

```bash
marfa login --url http://localhost:8600
```

Your browser opens with a code filled in. Select **Continue**, choose **Full access**, check that the code matches the one in the terminal, and select **Approve**. The CLI keeps its sign-in in your keychain.

</Step>
<Step>

### Save your first file

Save a file with a title and a tag:

<Terminal>

```bash
marfa items add ~/Downloads/receipt.pdf --title "Boiler receipt" --tag home
```

```text
added /Users/sam/Downloads/receipt.pdf as 01a1f43e-0d02-7667-85da-2ed1583cb655 (sha256:5a83…)
```

</Terminal>

Then find it:

<Terminal>

```bash
marfa search boiler
```

```text
score    id                                    type       when                      title
  1.000  01a1f43e-0d02-7667-85da-2ed1583cb655  core.file  2026-11-19T14:37:49.698Z  Boiler receipt
```

</Terminal>

The file is now an **item**, which [How Marfa works](/how-marfa-works) explains.

</Step>
<Step>

### Connect your agent

Add your instance's MCP server to your agent, then sign in to it:

<Tabs items={["Claude Code", "Codex"]}>
<Tab value="Claude Code">

```bash
claude mcp add --transport http --scope user marfa http://localhost:8600/mcp
```

Start Claude Code, type `/mcp`, choose **marfa** and sign in.

</Tab>
<Tab value="Codex">

```bash
codex mcp add marfa --url http://localhost:8600/mcp
codex mcp login marfa
```

</Tab>
</Tabs>

Your browser opens your instance's approval page. Choose **Full access**, or **Choose access** to pick what the agent may reach, and select **Approve**.

</Step>
<Step>

### Ask your agent

In a new session, ask in your own words:

```text
Find my boiler receipt in Marfa. Then save the photo at https://upload.wikimedia.org/wikipedia/commons/e/ed/01_Paella_Valenciana_original.jpg to Marfa as "Paella", tagged cooking.
```

The agent finds your receipt and saves the photo as a new file. `marfa search paella` finds it too: the CLI and the agent work from the same items.

</Step>
</Steps>
