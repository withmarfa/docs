Marfa is **one place for everything you keep,** your files first, which runs on your own computer and which every app and agent you approve can reach.

- **You'll build** a Marfa instance on your computer, with you as its owner.
- **You need** a Mac with Apple silicon or a Linux computer, a terminal, and Claude Code or Codex for the agent steps.
- **You'll have** a first file saved in Marfa, and an agent that finds it and saves more.

<Steps paged>
<Step>

### Install Marfa

One script installs the CLI, `marfa`, and the server, `marfa-server`, into `~/.local/bin`:

<Terminal>

```bash
curl -fsSL https://raw.githubusercontent.com/withmarfa/marfa/main/scripts/install.sh | sh
```

```text
Installed marfa 0.0.81 and marfa-server 0.0.81 to /Users/sam/.local/bin.
```

</Terminal>

If the script says that folder **is not on your `PATH`**, add the `export PATH=` line it prints to your shell's startup file, then open a new terminal.

</Step>
<Step>

### Start the server

Start a server that only this computer reaches, with no Docker or database to set up:

<Terminal>

```bash
marfa server install --access local
```

```text
Marfa 0.0.81 is running.
  Address   http://localhost:8600
Open this link to choose the owner's email and password. It works once, for five minutes; run this command again for a new one.
  http://localhost:8600/setup#handoff=6f1c…
```

</Terminal>

</Step>
<Step>

### Create your account

Open the link under **Open this link to choose the owner's email and password**. On **Create your account**, enter your name, email address and a password, and select **Create account**.

You're now the owner, and **nobody else can claim the instance.**

</Step>
<Step>

### Sign in from the CLI

```bash
marfa login --url http://localhost:8600
```

Your browser opens with a code filled in. Select **Continue**, choose **Full access**, check that the code matches the one in the terminal, and select **Approve**. The CLI keeps its sign-in in your keychain.

</Step>
<Step>

### Save your first file

Save any file you have, such as a PDF in your Downloads folder:

<Terminal>

```bash
marfa items add ~/Downloads/receipt.pdf
```

```text
added /Users/sam/Downloads/receipt.pdf as 01a1f46e-833a-77af-b9f7-9ccbf59e3dee (sha256:7937…)
```

</Terminal>

Then search for a word from its name:

<Terminal>

```bash
marfa search receipt
```

```text
score    id                                    type       when                      title
  1.000  01a1f46e-833a-77af-b9f7-9ccbf59e3dee  core.file  2026-11-19T15:30:45.689Z  receipt.pdf
```

</Terminal>

The file is now an **item**, titled with its file name. [How Marfa works](/how-marfa-works) explains items.

</Step>
<Step>

### Connect your agent

Add your instance's MCP server to your agent, then sign in to it:

<Tabs items={["Claude Code", "Codex"]}>
<Tab value="Claude Code">

```bash
claude mcp add --transport http --scope user marfa http://localhost:8600/mcp
```

Start Claude Code, type `/mcp`, choose **marfa** and sign in.

</Tab>
<Tab value="Codex">

```bash
codex mcp add marfa --url http://localhost:8600/mcp
codex mcp login marfa
```

</Tab>
</Tabs>

Your browser opens your instance's approval page. Choose **Full access**, or **Choose access** to pick what the agent may reach, and select **Approve**.

</Step>
<Step>

### Ask your agent

In a new session, ask in your own words, naming the file you saved and another file on your computer:

```text
Find my receipt in Marfa. Then save ~/Pictures/beach.png to Marfa, tagged holiday.
```

The agent finds your receipt. To save a file from your computer it runs `marfa items add`, so allow that command when it asks. `marfa search beach` finds the new file too: the CLI and the agent work from the same items.
