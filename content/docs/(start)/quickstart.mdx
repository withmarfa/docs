---
title: Quickstart
description: Install Marfa on your Mac or Linux computer, connect an agent to it, and save and find your first file.
---

- **You'll build** a Marfa instance on your own computer, with you as its owner.
- **You need** a Mac or a Linux computer, a terminal, and Claude Code or Codex if you want to try an agent.
- **You'll have** your first file saved in Marfa, and an agent that finds it and saves more.

The instance runs as a service in your own account, with no Docker and no database to set up, and starts again each time you sign in. To run Marfa on Railway instead, follow [Run Marfa on Railway or a server](/run/run-on-a-server) to claim it, then pick up at **Sign in from the CLI** with your Railway address in place of `http://localhost:8600`.

<Steps paged>
<Step>

### Install Marfa

One script installs the CLI, `marfa`, and the server, `marfa-server`, into `~/.local/bin`:

<Terminal>

```bash
curl -fsSL https://raw.githubusercontent.com/withmarfa/marfa/main/scripts/install.sh | sh
```

```text
Installed marfa 0.0.80 and marfa-server 0.0.80 to /Users/sam/.local/bin.

Set up a server on this machine:
  marfa server install
```

</Terminal>

If the script says that folder **is not on your `PATH`**, add the `export PATH=` line it prints to your shell's startup file, then open a new terminal.

</Step>
<Step>

### Start the server

Set up a server that only this computer reaches:

<Terminal>

```bash
marfa server install --access local
```

```text
Marfa 0.0.80 is running.

  Address   http://localhost:8600
  Folder    /Users/sam/marfa-server on sams-mac
  Service   the launchd agent so.marfa.server.marfa

Keep a copy of /Users/sam/marfa-server/marfa.env somewhere safe, outside this folder. It holds the two secrets the data needs, and they are not stored anywhere else.

Open this link to choose the owner's email and password. It works once, for five minutes; run this command again for a new one.
http://localhost:8600/setup#handoff=6f1c…
```

</Terminal>

**Copy `marfa.env` somewhere safe now,** such as your password manager: it holds two secrets your data needs, and they aren't kept anywhere else. The command also says that **no backups are kept** yet, which [Back up and restore](/run/back-up-and-restore) sets up. [Install on a Mac or Linux machine](/run/install) covers the other ways to reach the server, such as from your phone over Tailscale.

</Step>
<Step>

### Create your account

Open the link the command printed. On **Create your account**, enter your name, email address and a password, and select **Create account**.

You are now the owner of this instance. **Nobody else can claim it**, and the link stops working.

</Step>
<Step>

### Sign in from the CLI

Sign the CLI in to your instance:

```bash
marfa login --url http://localhost:8600
```

Your browser opens with a code filled in. Select **Continue**, check that the code matches the one in the terminal, and select **Approve** to give the CLI full access. The CLI keeps its sign-in in your keychain, so the commands that follow need no address or key.

</Step>
<Step>

### Save your first file

Save a file from your computer, with a title and a tag, then search for it:

<Terminal>

```bash
marfa items add ~/Downloads/receipt.pdf --title "Boiler receipt" --tag home
marfa search boiler
```

```text
added receipt.pdf as 01a1f121-6f4b-73b3-8579-1566739cafa1 (sha256:9c1f…)
score    id                                    type       when                      title
  1.000  01a1f121-6f4b-73b3-8579-1566739cafa1  core.file  2026-11-19T00:07:42.667Z  Boiler receipt
```

</Terminal>

The file is now an **item** of the type `core.file`: Marfa keeps its bytes, and the item holds its title, tag and type. A photo becomes a `core.file.image`. [Ideas in Marfa](/ideas-in-marfa) explains items and types.

</Step>
<Step>

### Connect your agent

Add your instance's MCP server to your agent, then sign in to it:

<Tabs items={["Claude Code", "Codex"]}>
<Tab value="Claude Code">

```bash command-check="other-tool"
claude mcp add --transport http --scope user marfa http://localhost:8600/mcp
```

Start Claude Code, type `/mcp`, choose **marfa** and sign in.

</Tab>
<Tab value="Codex">

```bash command-check="other-tool"
codex mcp add marfa --url http://localhost:8600/mcp
codex mcp login marfa
```

</Tab>
</Tabs>

Your browser opens your instance's approval page. Choose **Full access**, or **Choose access** to pick what the agent may reach, and select **Approve**.

</Step>
<Step>

### Ask your agent

In a new session, ask in your own words:

```text
Find my boiler receipt in Marfa. Then save https://www.rust-lang.org as a bookmark called "Rust home page", tagged learning.
```

The agent finds the file you saved, and saves the bookmark as a new item. `marfa search rust` shows it, so you can see that the CLI and the agent work from the same data.

</Step>
</Steps>
