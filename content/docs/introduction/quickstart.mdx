**This is the hosted path** — sign up on a hosted Marfa instance, get a credential, and create your first item. About a minute.

<Callout type="info">
  Prefer to run your own instance? See [Quickstart (self-hosted)](/introduction/quickstart-self-hosted) for the local-instance path.
</Callout>

<Steps>

<Step>

### Sign up and verify your email

Open `/auth/sign-up` on your hosted instance in a browser and create an account. Sign-up provisions a user and a tenant together in one transaction, so there is no separate tenant step.

A hosted instance with a real email backend requires verification before you can sign in. A confirmation email arrives at the address you supplied; click the link to verify, then sign in. Until then the account has no active session.

<Callout type="info">
  The same sign-up is also reachable programmatically at `POST /auth/sign-up/email`. The JSON response carries `{ user, session }`, but when email verification is on, `session.token` is null and no session cookie is set — you still verify first. The browser flow is the simpler on-ramp.
</Callout>

</Step>

<Step>

### Get a credential

The data plane is bearer-only. Every request to `/items`, `/keys`, and the rest carries an `Authorization: Bearer` token — either a long-lived API key (`marfa_k1_...`) or an OAuth access token (`marfa_at_...`). A Better Auth session cookie does not authenticate the data plane. Two self-serve paths produce a bearer:

<Tabs items={['Web console (API key)', 'CLI (device flow)']}>

<Tab value="Web console (API key)">

Signed in, open `/auth/keys`. Enter a label and create a key. The plaintext `marfa_k1_...` is shown once on that page — copy it now, the server never shows it again.

```bash
export MARFA_API_URL=https://your-marfa-instance.example
export MARFA_API_KEY=marfa_k1_...
```

</Tab>

<Tab value="CLI (device flow)">

The CLI signs in over the OAuth device flow — no key handling. It prints a URL and code; approve in a browser, and a `marfa_at_...` token persists at `~/.marfa/<instance>.json` and refreshes transparently.

```bash
marfa --url https://your-marfa-instance.example auth login
marfa auth whoami
```

Subsequent `marfa` commands use the stored token. See [CLI](/sdks/cli) for the full surface.

</Tab>

</Tabs>

</Step>

<Step>

### Create your first item

The curl calls below read `MARFA_API_URL` and `MARFA_API_KEY` from the environment, the web-console path above. If you took the CLI path instead, run `marfa items create --type core.note --prop body="Hello, Marfa." --tier library`.

```bash
curl -X POST $MARFA_API_URL/items \
  -H "Authorization: Bearer $MARFA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "type": "core.note",
    "properties": { "body": "Hello, Marfa." },
    "tier": "library"
  }'
```

The response is an envelope, not a bare item: `{ "item": { … }, "metadata": { … } }`. Under `item` you get server-stamped `id`, `created_at`, `version: 1`, the `source` stamped from your credential, and the body you sent. Under `metadata` you get the item's tags and extensions, empty on a fresh write.

The SDKs unwrap this for you and hand back the item directly. Only the raw HTTP path sees the envelope.

</Step>

<Step>

### Read it back

```bash
curl $MARFA_API_URL/items?type=core.note \
  -H "Authorization: Bearer $MARFA_API_KEY"
```

List responses are paginated: `{ "data": [ … ], "cursor": "…", "has_more": true }`. Your new item is the first entry in `data`.

</Step>

</Steps>

## Same flow from the SDKs

The TypeScript SDK collapses the last two steps into a single call:

```typescript
import { MarfaClient } from '@withmarfa/sdk';

const client = new MarfaClient({
  url: process.env.MARFA_API_URL!,
  apiKey: process.env.MARFA_API_KEY!,
});

const note = await client.items.create({
  type: 'core.note',
  properties: { body: 'Hello, Marfa.' },
  tier: 'library',
});

console.log(note.id);
```

Swift, identical shape:

```swift
import MarfaSDK

let client = MarfaClient(url: serverURL, apiKey: apiKey)

let note = try await client.items.create(
  CreateItemInput(
    type: "core.note",
    properties: ["body": .string("Hello, Marfa.")],
    tier: .library
  )
)
```
