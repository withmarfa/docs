**This is the self-hosted path** — clone the server, run it against SQLite with zero config, bootstrap the instance, and create your first item. A handful of commands, a few minutes.

<Callout type="info">
  Building against a hosted instance instead? See [Quickstart (hosted)](/introduction/quickstart) for the sign-up path. For the full operational picture — configuration, deployment, operations — see [Self-hosting](/self-hosting).
</Callout>

<Steps>

<Step>

### Clone and build

```bash
git clone https://github.com/withmarfa/marfa
cd marfa
pnpm install
pnpm build
```

</Step>

<Step>

### Start the server

```bash
export API_KEY_SALT="$(openssl rand -hex 32)"
export PORT=8600
node packages/server/dist/index.js
```

`API_KEY_SALT` is the only required environment variable; everything else uses sensible defaults — SQLite at `./data/marfa.db`, blobs in `./data/blobs/`, rate-limited at 1000 requests per minute per credential.

<Callout>
Integrations (calendar sync, webhooks, and the like) need Postgres and stay off on this SQLite quickstart. To run with Postgres and integrations, use the [Docker Compose quickstart](/self-hosting/run/docker-compose).
</Callout>

</Step>

<Step>

### Bootstrap the instance

A fresh server prints a one-time secret to its own log at startup. That secret is what the first `POST /keys` presents, and reading the log is what proves you are the person running the instance:

```
[warn] This instance holds no credential yet. Mint the first one with: curl -X POST <url>/keys -H "Authorization: Bearer 3f9c…" …
```

```bash
curl -X POST http://localhost:8600/keys \
  -H "Authorization: Bearer <the secret from the log>" \
  -H 'Content-Type: application/json' \
  -d '{"label":"operator","source":"operator"}'
```

**You get two credentials back, and the second is the one you work with.**

- **`key`** is the **operator key**. It runs the instance — creating spaces and accounts, minting keys into a named space — and it holds no space and no permissions of its own, so it cannot read or write anything. Put it somewhere safe and leave it there.
- **`space_key.key`** is bound to the space the same call provisioned, holds everything in it, and is the credential every command below uses.

Both plaintexts are shown once. The secret is consumed by the mint and reprinted at every boot until then, so a restart before you use it does not strand you. The window closes on the first successful create and does not reopen if the key is later revoked.

With the Marfa CLI, `marfa bootstrap http://localhost:8600 <secret>` does the same and saves the space key to `~/.marfa/default.json` so later commands authenticate automatically.

```bash
export MARFA_API_URL=http://localhost:8600
export MARFA_API_KEY=marfa_k1_...
```

</Step>

<Step>

### Create your first item

```bash
curl -X POST $MARFA_API_URL/items \
  -H "Authorization: Bearer $MARFA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "type": "core.note",
    "properties": { "body": "Hello, Marfa." },
    "tier": "library"
  }'
```

The response is an envelope, not a bare item: `{ "item": { … }, "metadata": { … } }`. Under `item` you get server-stamped `id`, `created_at`, `version: 1`, your `source: "bootstrap"`, and the body you sent. The SDKs unwrap this for you; only the raw HTTP path sees the envelope.

</Step>

<Step>

### Read it back

```bash
curl $MARFA_API_URL/items?type=core.note \
  -H "Authorization: Bearer $MARFA_API_KEY"
```

You'll see the item you just created in the result set.

</Step>

</Steps>

## Same flow from the SDKs

The TypeScript SDK points at your own URL — the only difference from hosted is where it connects:

```typescript
import { MarfaClient } from '@withmarfa/sdk';

const client = new MarfaClient({
  url: process.env.MARFA_API_URL!,
  apiKey: process.env.MARFA_API_KEY!,
});

const note = await client.items.create({
  type: 'core.note',
  properties: { body: 'Hello, Marfa.' },
  tier: 'library',
});

console.log(note.id);
```

Swift, identical shape:

```swift
import MarfaSDK

let client = MarfaClient(url: serverURL, apiKey: apiKey)

let note = try await client.items.create(
  CreateItemInput(
    type: "core.note",
    properties: ["body": .string("Hello, Marfa.")],
    tier: .library
  )
)
```
