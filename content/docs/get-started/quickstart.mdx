Sign up on a hosted Marfa instance, mint an API key, and create your first item — a handful of curl calls, about a minute.

<Callout type="info">
  Prefer to self-host? See the [Self-host quickstart](/docs/self-hosting/self-host-quickstart) for the local-instance path.
</Callout>

<Steps>

<Step>

### Sign up for an account

A hosted Marfa instance exposes Better Auth's email + password sign-up at `/auth/sign-up/email`:

```bash
curl -X POST https://your-marfa-instance.example/auth/sign-up/email \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "you@example.com",
    "password": "a-strong-passphrase",
    "name": "Your Name"
  }'
```

The response carries a signed-in session. A confirmation email arrives at the address you supplied — verify it before moving on.

</Step>

<Step>

### Create an API key

Once you've signed in to the console (or programmatically using the session bearer), mint a scoped API key. The simplest one — `core.note` read and write — looks like this:

```bash
curl -X POST https://your-marfa-instance.example/keys \
  -H 'Authorization: Bearer <session-token>' \
  -H 'Content-Type: application/json' \
  -d '{
    "label": "quickstart",
    "role": "member",
    "source": "Quickstart",
    "type_permissions": { "core.note": "write" }
  }'
```

The response includes the plaintext key once — `marfa_k1_...`. Store it; the server never shows it again.

```bash
export MARFA_API_URL=https://your-marfa-instance.example
export MARFA_API_KEY=marfa_k1_...
```

</Step>

<Step>

### Create your first item

```bash
curl -X POST $MARFA_API_URL/items \
  -H "Authorization: Bearer $MARFA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "type": "core.note",
    "properties": { "body": "Hello, Marfa." },
    "tier": "library"
  }'
```

The response is a full item — server-stamped `id`, `created_at`, `version: 1`, your `source: "Quickstart"`, the body you sent.

</Step>

<Step>

### Read it back

```bash
curl $MARFA_API_URL/items?type=core.note \
  -H "Authorization: Bearer $MARFA_API_KEY"
```

You'll see the item you just created in the result set.

</Step>

</Steps>

## Same flow from the SDKs

The TypeScript SDK collapses the last two steps into a single call:

```typescript
import { MarfaClient } from '@withmarfa/sdk';

const client = new MarfaClient({
  url: process.env.MARFA_API_URL!,
  apiKey: process.env.MARFA_API_KEY!,
});

const note = await client.items.create({
  type: 'core.note',
  properties: { body: 'Hello, Marfa.' },
  tier: 'library',
});

console.log(note.id);
```

Swift, identical shape:

```swift
import MarfaSDK

let client = MarfaClient(url: serverURL, apiKey: apiKey)

let note = try await client.items.create(
  CreateItemInput(
    type: "core.note",
    properties: ["body": .string("Hello, Marfa.")],
    tier: .library
  )
)
```
