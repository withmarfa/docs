Each line names one thing you can use and links to the page that explains it. Where Marfa keeps a full list of something, the line links to that list: the types, the settings, the permissions, the error codes and the commands.

## Store and organize items

- **Store typed items.** Every item has a type, and Marfa refuses a write that breaks the type. [Items and types](/get-started/items-and-types), [Create an item](/api-reference/items/createItem)
- **Start from the core types.** Marfa ships types for notes, tasks, bookmarks, highlights, messages, events, people, places, media and files. [List types](/api-reference/types/listTypes) lists them all.
- **Register your own types.** A type of yours can inherit from another type. [Define a type](/guides/define-a-type), [Register a type](/api-reference/types/registerType)
- **Join items with edges.** An edge is a typed, directed link with properties of its own. Marfa ships ten edge types, and you can register more. [Properties, metadata and edges](/get-started/properties-metadata-and-edges), [Create an edge](/api-reference/edges/createEdge), [List edge types](/api-reference/edge-types/listEdgeTypes)
- **Tag items and add extensions.** Tags are free-form labels, and an extension namespace holds data that an app defines. [Properties, metadata and edges](/get-started/properties-metadata-and-edges), [Add tags to an item](/api-reference/metadata/addItemTags), [Replace an extension namespace](/api-reference/extensions/replaceItemExtension)
- **Keep what arrives apart from what you keep.** The feed tier holds incoming records, and the library tier holds what a person chose to keep. [Items and types](/get-started/items-and-types#feed-and-library)
- **Archive, trash and restore.** An item moves between states, and a trashed item stays recoverable until it's purged. [Change an item's state](/api-reference/items/transitionItem), [Restore an item](/api-reference/items/restoreItem), [Purge an item](/api-reference/items/purgeItem)
- **Write in bulk.** One request upserts many items, and a bulk action changes every item that matches a filter, as a background job. [Upsert items in bulk](/api-reference/items/bulkUpsertItems), [Apply a bulk action](/api-reference/bulk-actions/applyBulkAction)
- **Record recurring events.** One event item carries recurrence rules, and Marfa computes its occurrences for the window you ask about. [List occurrences](/api-reference/items/listOccurrences), [Occurrences chapter of the contract](https://github.com/withmarfa/marfa/blob/main/conformance/spec/occurrences.md)

## Find and read items

- **List and filter.** Narrow a listing by type, state, source, tags, tier and time, and sort it. [List, filter and search](/guides/list-filter-search), [List items](/api-reference/items/listItems)
- **Search the text.** [Search items](/api-reference/search/searchItems) ranks the items whose text or tags match.
- **Count items.** [Get item counts](/api-reference/items/getItemStats)
- **Look up an item.** Find items by ID, natural key or link, in any state. [Look up items](/api-reference/items/lookupItems), [Get items in bulk](/api-reference/items/bulkGetItems)

## Files

- **Upload and download files.** Marfa stores a file's bytes by their hash, and an item refers to them. [Files](/get-started/files), [Upload a blob](/api-reference/blobs/uploadBlob), [Download a blob](/api-reference/blobs/downloadBlob)
- **Share a file by link.** A link serves the bytes for a limited time to a request with no credential. [Get a blob URL](/api-reference/blobs/getBlobUrl)
- **Keep copies in more than one place.** The instance's disk can be joined by an S3-compatible object store, and Marfa replicates and checks each copy. [Handle files](/guides/handle-files), [List blob stores](/api-reference/blobs/listBlobStores)
- **Read text and dimensions from files.** Marfa writes a file's extracted text, and an image's width and height, onto the file item. [Housekeeping](/guides/housekeeping)
- **Find files nothing refers to.** [List orphaned blobs](/api-reference/blobs/listBlobOrphans)

## History and safe writes

- **Look back at an item's versions.** Marfa keeps a snapshot of each version, and thins old ones on a schedule. [Changes over time](/get-started/changes-over-time), [List item versions](/api-reference/items/listItemVersions)
- **Write without overwriting.** A write names the version it read. Marfa merges a stale write when it can, and refuses it with `409 version_conflict` when it can't. [Write safely](/guides/write-safely), [Update an item](/api-reference/items/updateItem)
- **Repeat a write safely.** A request sent again with the same `Idempotency-Key` gets the first request's answer. [Write safely](/guides/write-safely)

## Keep in step

- **Follow changes as they happen.** Every change is an event in one log. A stream sends them live, resumes from a cursor, and filters by type. [Staying in step](/get-started/staying-in-step), [Keep in sync](/guides/keep-in-sync), [Stream change events](/api-reference/event-stream/streamEvents)
- **Receive events at a URL.** A webhook delivers matching events, signed, with retries and a redelivery of a failed one. [Create a webhook](/api-reference/webhooks/createWebhook), [Redeliver a failed delivery](/api-reference/webhooks/redeliverWebhookDelivery)
- **Keep a working copy on a device.** A device holds a slice of the instance, reads it offline, and queues its writes until it can send them. [Devices and folders](/get-started/devices-and-folders), [Swift package](/tools/swift-package)
- **Keep a directory in step with items.** A folder holds a slice of the instance as files, and an edit on either side reaches the other. [Devices and folders](/get-started/devices-and-folders), [Create a folder](/api-reference/folders/createFolder)

## Connect other services

- **Run a connector.** A program outside the server registers, sends heartbeats, and reports each run. [Connectors](/get-started/connectors), [Build a connector](/guides/connector), [Register a connector](/api-reference/connectors/registerConnector)
- **Keep a connector's state on the instance.** A connector stores what it needs to resume, and holds its registration so that one process at a time works. [Holds and retries](/guides/connector-holds-and-retries), [Replace the state document](/api-reference/connectors/replaceConnectorState), [Take or renew a hold](/api-reference/connectors/holdConnector)
- **Receive another service's webhooks.** An endpoint takes deliveries with no credential, and the connector reads and handles them. [Connector webhooks](/guides/connector-webhooks), [Create a webhook endpoint](/api-reference/connectors/createInboundEndpoint)

## Access and sign-in

- **Give a key narrow access.** A key's five maps name the content it reads and writes, and its permissions name the other operations it may use. [Keys and permissions](/get-started/keys-and-permissions) lists the twelve permissions. [Create an API key](/api-reference/access/createKey)
- **Let apps sign in.** An app registers itself, and you approve what it can reach. [Authenticate](/guides/authenticate), [Register an OAuth client](/api-reference/access/registerOAuthClient)
- **Claim an instance as its owner.** [Run an instance](/get-started/run-an-instance), [Claim the instance](/api-reference/access/createOwner)
- **Enforce the shape of writes.** The instance, or a single key, can refuse unknown properties and limit which sources write or show items of a type. [Settings](/guides/settings)
- **Read the audit log.** [Audit log](/guides/audit-log), [List audit log entries](/api-reference/instance/listAuditLog)

## Run an instance

- **Run it on your own machine.** Marfa keeps its data in one SQLite database file and a directory of blobs. [Run an instance](/get-started/run-an-instance), [Deploy](/guides/deploy)
- **Configure it.** Environment settings are read when the server starts, and some settings change while it runs. [Settings](/guides/settings) lists every setting. [Get the configuration](/api-reference/instance/getConfig), [Replace the configuration](/api-reference/instance/replaceConfig)
- **Run housekeeping.** Scheduled jobs purge the trash, thin versions, clear old records and look after blobs, and you can list them and run one now. [Housekeeping](/guides/housekeeping), [List housekeeping jobs](/api-reference/instance/listHousekeeping)
- **Back up and restore.** An export writes items and edges as lines of JSON or as an archive, and a restore reads the archive. [Back up and restore](/guides/back-up-and-restore), [Export items and edges](/api-reference/export-and-restore/exportData), [Restore from an archive](/api-reference/export-and-restore/restoreArchive)
- **Move to a new build.** Marfa doesn't upgrade a database in place: you export with the build that wrote it, start a fresh file, and restore the archive. A build that can't use a database refuses to start and says why. [Upgrade](/guides/upgrade)
- **Watch it.** Read what the instance reports about itself and its counters, send traces and logs to OpenTelemetry, post server errors to a webhook, and ping a monitor. [Describe the instance](/api-reference/instance/getInstance), [Get server metrics](/api-reference/instance/getServerMetrics), [Settings](/guides/settings)
- **Limit request rates.** The server limits the requests each credential makes. The `rate_limited` refusal tells a client to wait. [Settings](/guides/settings), [Errors](/api-reference/errors)

## Clients and tools

- **The HTTP API.** Every operation is documented and generated from the API description. [API reference](/api-reference), and [Errors](/api-reference/errors) lists every error code.
- **The `marfa` command.** Every published operation is a command, and it keeps a working copy and folders too. [The marfa command](/tools/marfa-command) lists every command.
- **The Swift package.** Apple apps keep a working copy and a queue of writes. [Swift package](/tools/swift-package)
- **The TypeScript client.** A client typed from the API description. [TypeScript client](/tools/typescript-client)
- **Docs for agents.** An agent reads these docs through the `marfa docs` command, an MCP server, JSON addresses and Markdown. [Docs for agents](/tools/docs-for-agents)
